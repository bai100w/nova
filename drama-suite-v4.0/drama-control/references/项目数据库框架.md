# 项目数据库框架

本文件规定每个项目必须提供哪些资料，以及各模块去哪里读、往哪里写。它只定义槽位和传递关系，不保存任何具体作品的值。

## 基本原则

- `剧集数据库/项目索引.md` 是唯一入口。每个槽位当前以哪个文件、哪一节为准，由索引声明。
- 下面的文件名是推荐结构，不强制。项目可以合并或拆分文件，但索引必须逐项指到具体文件和章节。
- 还没确定的值写“待定”。不删字段，也不从别的项目、旧聊天或 skill 里猜。
- 同一个字段只有一个当前权威来源。历史版本保留，但不与当前值并列生效。
- 新决定先写回对应的资料，再传到剧本、资产、分镜、制作包和物料。不只改下游交付物。

## 十类槽位

| 槽位 | 必须记录 | 推荐文件 |
|---|---|---|
| 创作方向与档案 | 形态、时长、主副题材、流程档位、画幅与发布平台；导演阐述与视觉圣经的位置；项目自建或覆写的档案 | `项目设定.md`、`导演阐述与视觉圣经.md`、`profiles/` |
| 世界观与剧情机制 | 时代地域、现实与虚构的边界、核心规则及其代价、禁区、时间线、主题 | `项目设定.md` |
| 剧情与集数 | 总体梗概、主线的目标与阻力、分集大纲、当前集状态、当前源稿与历史稿 | `剧情与集数.md`、剧本目录 |
| 人物与关系 | 角色编号、身份、年龄阶段、欲望与缺陷、关系、各自已知的信息、人物弧、说话习惯 | `人物关系.md` |
| 资产与版本 | 角色、场景、道具、风格对标、声音的编号、路径、版本、状态、控制权、适用范围 | `资产索引.md`、`资产登记.json` |
| 尺寸与连续性 | 身高与相对比例、道具实物尺寸、左右手与持物侧、空间位置、适用场次 | `尺寸与连续性.md` |
| 影像与声音参数 | 画幅、画风、画面预设表、色彩、光线、字幕开关与语言、声线、音乐与环境声的取舍 | `影像与声音参数.md`、`patterns/visual.md` |
| 生成配置 | 所选模型及其适配卡、调用方式、预算与重试上限、核验日期。密钥只放安全凭据 | `生成配置.md`、`models/` |
| 制作状态 | 各集的源稿、台词、资产、分镜、预演、生成包、成片、物料的当前版本、状态、阻断项、下一步 | `制作状态.md`、`gates/` |
| 学习与变更 | 参考卡、已采用的规律及适用范围、每集复盘、变更的旧值新值原因日期 | `references/`、`patterns/`、`更新日志.md` |

旧项目只有后九类。接手旧项目时在索引里补上“创作方向与档案”的映射，内容未定的标待定，其余不动。

## 推荐目录

```
<项目根目录>/
├── 剧集数据库/
│   ├── 项目索引.md
│   ├── 项目设定.md
│   ├── 导演阐述与视觉圣经.md
│   ├── 剧情与集数.md
│   ├── 人物关系.md
│   ├── 资产索引.md
│   ├── 资产登记.json
│   ├── 尺寸与连续性.md
│   ├── 影像与声音参数.md
│   ├── 生成配置.md
│   ├── 制作状态.md
│   ├── 更新日志.md
│   ├── models/        本项目填好的模型适配卡
│   ├── profiles/      本项目自建或覆写的档案
│   ├── patterns/      script.md、assets.md、visual.md、materials.md
│   ├── references/    参考卡 REF-日期-序号.md
│   └── gates/         关卡记录、评审记录
├── 资产/               角色、场景、道具、风格、声音的原始文件
└── 制作/
    └── EP01/           各集的剧本、分镜、预演、制作包、生成、审片、后期、宣发
```

资料库是项目里的一个文件夹，不是 skill。项目自己的适配卡、档案和规律都放在这里，升级 skill 套组时不会被覆盖。

## 模块读写对照

| 模块 | 必读槽位 | 主要回写 |
|---|---|---|
| drama-control | 全部十类 | 项目索引、制作状态、关卡记录、制作包登记、更新日志 |
| drama-script | 创作方向、世界观、剧情、人物关系、制作状态 | 剧本各级稿件、逐段拆解、台词表、剧情与人物的变更 |
| drama-direction | 创作方向、世界观、剧情、人物关系、学习与变更 | 导演阐述与视觉圣经、画面预设表、影像与声音参数 |
| drama-assets | 创作方向、剧情需求、人物关系、资产、尺寸、影像与声音 | 资产索引与登记、尺寸与连续性、验收状态 |
| drama-storyboard | 创作方向、当前剧本、人物关系、资产、尺寸、影像与声音、生成配置 | 逐镜设计、预演包、生成包、连续性状态 |
| drama-production | 当前制作包、资产、尺寸、影像与声音、生成配置、制作状态 | 请求记录、输出、审片结论、返修状态 |
| drama-editing | 创作方向、当前剧本与分镜、影像与声音、制作状态 | 预演、剪辑决策单、成片、终检清单结果 |
| drama-materials | 创作方向、剧情钩子、人物关系、已确认资产、影像与声音 | 物料版本、文案、导出规格 |
| drama-learning | 与参考相关的槽位、学习与变更 | 参考卡、patterns、复盘记录、更新日志 |

## 初始化步骤

1. 盘点项目里已有的文件，不复制其他作品的值。
2. 用 [项目索引模板](../templates/项目索引模板.md) 建索引，逐项填十类槽位的权威文件或章节。多个槽位可以指向同一文件的不同章节。
3. 每个字段标明：已确认、候选、待定或停用，并写来源和日期。
4. 检查人物、剧情、尺寸、影像、声音、生成参数能否各自从索引追到唯一的当前值。
5. 只补齐当前任务需要的内容，其余待定项保留。不因为未知而删掉框架。
6. 用 [制作状态模板](../templates/制作状态模板.md) 起制作状态。
