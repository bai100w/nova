# 流程与关卡

## 全剧级阶段（一个项目做一次）

| 阶段 | 主责模块 | 输入 | 交付 | 完成标准 |
|---|---|---|---|---|
| 立项定档 | drama-control | 用户的创意、素材、要求 | 资料库、项目索引、七项定档结果 | 十类槽位都有入口，未知项标待定 |
| 剧本开发 | drama-script | 创意或已有稿件、题材与时长档案 | 一句话梗概、人物与关系、分集大纲 | 评分达标；主线和每集核心事件清楚 |
| 导演与视觉开发 | drama-direction | 剧本开发成果、题材与形态档案、参考 | 导演阐述、视觉圣经、画面预设表、表演基调、声音概念、风格测试 | 评分达标；用户认可风格测试 |
| 全剧资产 | drama-assets | 人物表、视觉圣经、形态档案 | 主要角色、常用场景、固定声线 | 实际看过听过；登记进资产索引 |

已有成稿剧本的项目，剧本开发阶段改为“剧本体检”：按评分表检查现有稿件，列出问题和修改建议，由用户决定改不改。不擅自重写用户的定稿。

## 单集级阶段（每集循环）

| 阶段 | 主责模块 | 输入 | 交付 | 完成标准 |
|---|---|---|---|---|
| 单集剧本定稿 | drama-script | 分集大纲、导演阐述 | 节拍表、定稿、逐段拆解表、台词表、朗读计时；短片为剧本单文件 | 评分达标；时长经脚本核对，在时长档范围内 |
| 单集资产设计 | drama-assets | 逐段拆解 | 本集五类资产总表、新增项的设定卡 | 必须项都有设计 |
| **资产关卡·设计级** | drama-control | 资产总表与设定卡 | 关卡记录 | 见下 |
| 分镜，与资产制作并行 | drama-storyboard；drama-assets | 定稿、资产设定卡、画面预设表、模型适配卡 | 逐镜设计、连续性状态表；资产文件与验收记录 | 评分达标；必须项实际验收 |
| 预演 | drama-storyboard；文字卡预演片由 drama-editing 生成 | 分镜、确认台词、时长档案 | 预演清单、一页预演摘要；按档位加文字卡预演片、关键镜头静帧 | 摘要里的问题已修改或已说明保留理由 |
| **资产关卡·文件级** | drama-control | 资产文件与验收记录、分镜 | 关卡记录、冻结清单与白名单、分镜复核结果 | 见下 |
| **预演关卡** | drama-control | 预演摘要、分镜评审记录、生成包 | 关卡记录、锁定的分镜版本与生成包 | 见下 |
| 生成与审片 | drama-production | 制作包、适配卡 | 素材、请求记录、审片记录 | 每镜有审片结论；需返修的已处理 |
| 后期 | drama-editing | 通过审片的素材 | 剪辑、声音、调色、字幕包装后的成片 | 评分达标 |
| **终检** | drama-control | 成片、终检清单 | 关卡记录 | 见下 |
| 宣发 | drama-materials | 成片、已确认资产 | 封面、标题、文案 | 评分达标；发布另需授权 |
| 复盘 | drama-learning | 本集全部记录 | 复盘记录、候选规律 | 写明哪些规则有效、哪些要改 |

## 资产关卡（两级）

资产关卡分两级。设计级通过后就可以做分镜和纸面预演，资产的实际制作与分镜并行；文件级通过后才能锁定分镜、建制作包、付费生成。这样既不会在没有资产的情况下花钱，也不会因为资产还没生成就让整条流程停下来。

### 设计级（分镜前）

**放行条件：**

1. 本集源稿的每一段对白、旁白、动作、换场、道具交互，都能在五类资产总表里找到对应项。
2. 每个必须项都有设定卡或设计说明：角色的外形与造型、场景的布局与光源、道具的尺寸与状态、声线的描述。
3. 标“不适用”的项写了原因。
4. 控制权的规划清楚：每个属性将由哪一项资产控制，没有两项争同一属性。
5. 导演阐述的基调已确认（风格测试可以还没完成）。

**通过后可以做：** 分镜、纸面预演、文字卡预演片，同时开始制作资产。分镜依据设定卡设计，标为“待资产复核”。

**不可以做：** 锁定分镜和生成包、建制作包、付费生成视频。

### 文件级（锁定分镜前）

**放行条件：**

1. 五类资产的必须项都有真实可打开的文件，并且实际看过或听过。
2. 风格测试已通过，认可范围写清楚了。风格通过不等于人脸、服装、场景、道具、声音通过。
3. 身份、妆造、场景、道具、比例、声音之间没有控制权冲突，同一属性只有一个权威参考。
4. 被用户否定的、中断没有输出的材料已排除。
5. 每项的来源和版本可追溯。
6. **分镜已对照实际资产复核：** 实际做出来的场景布局、人物比例、道具外观，与设计时有出入的，受影响的镜头已经改过。

通过时冻结资产版本，生成本集白名单。

文件级可以在预演之前或之后通过，但必须在预演关卡之前。

### 各档位

小样档的资产范围更小（只做出镜必需项），但两级都照常执行。

## 预演关卡（付费生成前）

预演的作用是在花钱之前把问题找出来。它分三层，只有第一层所有档位必做：

| 层 | 成本 | 检查什么 |
|---|---|---|
| 纸面预演：时间线、结构检查、盲读测试 | 只有 token | 时长、钩子位置、台词、节奏是否平、覆盖、轴线、看不看得懂、预算 |
| 文字卡预演片 | 几乎为零，脚本自动生成 | 真实的时间感 |
| 关键镜头静帧 | 少量生图费用 | 关键画面的实际观感 |

各档位做到哪一层见 [流程档位](流程档位.md)。做法见分镜模块的纸面预演和剪辑模块的动态预演组装。

**放行条件：**

1. 总时长在时长档范围内。
2. 开场钩子在时长档规定的时间内出现。
3. 盲读测试的复述与剧本一致：谁、在哪里、想要什么、发生了什么变化。
4. 节奏与情绪曲线一致，有主峰；中片和长片有气口。没有连续多镜同景别、同强度造成的平。
5. 每场戏有建立、关键动作、反应，素材够剪。轴线和视线没有明显错误。
6. 确认台词完整，没有为了塞进时长而删台词或加快语速。
7. 模型做不好的高风险镜头已标记，并且有拆镜或替代方案。
8. 生成预算（镜数乘以重试上限）在授权范围内。
9. 分镜的评审记录存在且达标。
10. 资产关卡文件级已通过。

**谁来判定：** 总控按清单逐条判定，然后把一页预演摘要交给用户确认。用户看摘要即可，不必看完整分镜。精品档另请用户看文字卡预演片。用户已授权自动判定的，总控判定后直接放行，摘要留档。

通过后锁定分镜版本和生成包。之后再改分镜，受影响的包重新过本关卡的相关条目。

小样档可以不做盲读测试，在关卡记录里注明；第 1、2、6、7、8 条仍然要查。

## 终检（发布前）

终检由独立评审完成，做法见 [质量评审规范](质量评审规范.md)。具体清单在 drama-editing 模块。

**检查范围：**

1. 叙事：只看成片能看懂，钩子、转折、结尾都落地。
2. 与源稿核对：确认台词逐句在，没有错序、改写、漏句。
3. 一致性：人脸、服装、道具、声线在全片各镜之间一致。
4. 音画：对白清楚，音乐音效不抢词，切点没有噪声跳变。
5. 字幕与包装：文字正确可读，不遮挡关键内容，符合项目的字幕开关。
6. 技术规格：画幅、分辨率、帧率、时长、响度都是实测值，符合项目配置。
7. 版权与平台：音乐、字体、素材的授权状态已登记，符合发布平台要求。

没看过、没听过的部分标“未核验”，带有未核验项的终检不能记为通过。

通过后才能把成片交给宣发。发布本身另需用户授权。

## 上游变更怎么传到下游

| 上游变了什么 | 需要标“需复核”的下游 |
|---|---|
| 形态、时长、题材、档位 | 全部在制交付 |
| 导演阐述或视觉圣经 | 资产、分镜、调色与包装、宣发物料 |
| 剧本的剧情或人物设定 | 资产总表、分镜、生成包、剪辑 |
| 确认台词 | 朗读计时、分镜时长与分包、配音、字幕 |
| 角色或场景资产 | 用到它的分镜、生成包、已生成素材、宣发物料 |
| 声线 | 配音、用到它的生成包、剪辑的声音部分 |
| 生视频模型或适配卡 | 分包、全部生成请求 |
| 分镜 | 生成包、预演、剪辑决策单 |

处理顺序：先把变更写回对应的上游资料并记入更新日志，再标记下游，最后只返修受影响的范围。不静默覆盖已经通过的成片。
