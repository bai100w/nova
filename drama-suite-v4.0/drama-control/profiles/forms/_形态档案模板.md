# 形态档案模板

形态档案描述一种视觉形态的技术特点和默认做法。它是硬约束：某个形态做不到或做不好的事，不因题材需要而硬做。

新建档案时复制本模板，文件名用形态名，例如 `真人短剧.md`。套组自带的档案放在本目录，项目自建或覆写的档案放在项目资料库的 `profiles/forms/`，同名时以项目里的为准。

每一节写具体做法和理由，不写空泛的形容词。还不确定的项写“待定”，不要猜。
