# 时长档案模板

时长档案描述一个篇幅档位的结构和制作默认值。它是硬约束：篇幅装不下的内容要回到剧本取舍，不靠加快语速或删台词硬塞。

新建档案时复制本模板，文件名用档位名，例如 `短片-1分钟内.md`。套组自带的档案放在本目录，项目自建或覆写的放在项目资料库的 `profiles/durations/`，同名时以项目里的为准。

带数字的项目是起点值，写明依据，并在项目跑过之后校准。
