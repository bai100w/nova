# 中片（3 分钟左右）

- 目标时长：约 3 分钟，常见 2.5 到 3.5 分钟。具体范围在项目配置里写
- 档案版本与日期：v1，2026-11-13
- 依据：短剧的通用结构。数值都是起点值，需要用实际项目校准

## 1. 结构模板

压缩的三幕。

| 节拍 | 任务 | 大致位置 |
|---|---|---|
| 开场钩子 | 冲突进行中，或一个反常的画面 | 0 到 5 秒 |
| 建立 | 人物的欲望和阻力 | 到 15% 左右 |
| 升级 | 处境一步步变难，至少一次加码 | 15% 到 55% |
| 低点或主反转 | 局面彻底改变 | 55% 到 75% |
| 回应 | 人物在新局面下的选择 | 75% 到 90% |
| 集尾钩子或落点 | 连载留钩子，单集收住 | 最后 10% |

## 2. 钩子

- 开场钩子最晚：5 秒
- 中途再抓注意力：中段（约 1 分 30 秒前后）安排一次加码或新信息
- 结尾：连载用集尾钩子；单集用落点

## 3. 人物与场景规模

- 主要人物：2 到 4 个
- 场景：2 到 4 个
- 超出时：先列资产预算，由用户决定

## 4. 节奏

- 整体：有一次明显的缓急变化
- 主反转之前适当放慢，让观众产生预期
- 集尾钩子之后快速收住
- 信息密度：允许个别镜头只承担情绪，不承担新信息

## 5. 镜头量

- 镜头数：约 45 到 70 个
- 平均镜头长度：2.5 到 4 秒
- 依据：按平均镜头长度估算

## 6. 流程默认值

- 默认流程档位：标准
- 预演：纸面预演含盲读；环境支持时加文字卡预演片
- 连续性管理：中。按生成包记连续性状态表

## 7. 常见问题

| 问题 | 表现 | 对策 |
|---|---|---|
| 中段原地打转 | 同一种冲突重复两三次 | 每次加码都要让处境更难，或换一种阻力 |
| 反转没有铺垫 | 观众觉得突然 | 在前半段埋一处可回收的信息 |
| 集尾钩子硬塞 | 最后突然出现一个无关的新事件 | 钩子从本集的冲突里长出来 |
| 节奏一直平 | 每个镜头长度相近 | 对照情绪曲线，紧的地方短、松的地方长 |
