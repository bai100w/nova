# 逆袭复仇

- 类型：叙事方式（先压后放）
- 主要受众与常见平台：受众广泛；短剧平台的主流题材之一
- 档案版本与日期：v1，2026-11-13
- 依据：通用的爽剧类型经验。需要用对标作品和实际数据校准

## 1. 观众承诺

- 核心情绪：先被压抑激起愤怒和不甘，再在释放时获得爽感
- 最不能接受的落空：压了太久不放；放的时候不够痛快；主角赢得太轻松，没有分量

## 2. 钩子

- 常用开场钩子：主角正在遭受最大的屈辱；主角的真实身份或实力被隐藏的瞬间；主角重生或获得能力的时刻
- 密度：高。短剧里通常每一两分钟就有一次小的打脸或反击
- 有效的钩子：让观众站在主角一边的不公。无效的钩子：主角的处境不能引起同情

## 3. 人物与关系

- 主角类型：被低估的人，有隐藏的身份、能力或决心
- 对手：嚣张、看不起主角的人。对手越嚣张，打脸越痛快
- 张力来源：权力不对等和信息不对等（观众知道主角的真实实力，对手不知道）
- 避免脸谱：对手可以坏，但要有让人信服的动机，否则打脸没有分量

## 4. 节奏与反转

- 走向：压、压、放；再压、再放，一次比一次大
- 反转：身份揭示、实力展示、证据摆出。铺垫要让观众提前知道，等着看对手的反应
- 需要给足时间：打脸的瞬间之后，对手的反应和周围人的反应

## 5. 视觉倾向

- 色调：压抑时冷、暗、低饱和；释放时亮、暖、高对比
- 光线：压抑时主角处在暗处；释放时主角被光照亮
- 镜头：压抑时俯拍主角、仰拍对手；释放时反过来
- 标志性画面：对手难以置信的表情；主角从容的姿态

## 6. 声音倾向

- 音乐：压抑时低沉；释放时有力的节奏，鼓点
- 音效：打脸的瞬间用短促有力的冲击音
- 静默：揭示身份之前的一拍

## 7. 集尾钩子

- 常用：主角即将出手的瞬间；对手即将发现真相；新的更强的对手出现
- 好的集尾：让观众期待下一次释放。差的集尾：刚放完又无理由地压回去

## 8. 雷区

| 雷区 | 表现 | 对策 |
|---|---|---|
| 压得太久 | 观众看了好几集都在受气 | 每集都要有释放，哪怕是小的 |
| 打脸重复 | 每次都是同样的方式 | 换释放的方式：身份、实力、证据、众人站队 |
| 主角变得和对手一样 | 主角的报复过度，失去同情 | 主角的反击要有分寸和底线 |
| 对手太蠢 | 对手的失败是因为蠢，不是因为主角强 | 对手要有实力，主角要赢得有难度 |

可以打破的惯例：最后的复仇可以是放下，而不是报复，只要主角的选择让人信服、并且仍然给观众释放感。

## 9. 给各模块的提示

| 模块 | 这个题材要特别注意的 |
|---|---|
| 剧本 | 压和放的节奏表要清楚；打脸要有铺垫，观众要先知道 |
| 导演与视觉开发 | 用色彩和光线区分压抑和释放 |
| 资产 | 主角的造型要有“隐藏”和“揭示”两个状态 |
| 分镜 | 角度的变化表现权力的变化；打脸后给足反应镜 |
| 剪辑与后期 | 释放的瞬间音画配合要有冲击力 |
| 宣发物料 | 封面用主角最从容、对手最狼狈的对比 |
