# 题材档案模板

题材档案描述一类故事的观众期待和惯用手法。它是审美倾向，不是硬约束：与形态的技术约束或时长的篇幅约束冲突时让步，与用户的明确决定冲突时以用户为准。

新建档案时复制本模板，文件名用题材名，例如 `悬疑.md`。套组自带的档案放在本目录，项目自建或覆写的放在项目资料库的 `profiles/genres/`，同名时以项目里的为准。

## 叠加

一个项目选一个主题材，可以再选一个副题材。有的题材是叙事方式（例如升级流、无限流），有的是世界观设定（例如玄幻、末日），两类经常组合。叠加时：

- 主题材决定观众承诺、钩子和节奏。
- 副题材补充世界观、视觉和声音上的特征。
- 两者冲突时以主题材为准，取舍结果写进项目配置。

## 写法要求

- 每一节写具体做法，并说明它为什么对这类观众有效。只写“要有张力”“要高级”等于没写。
- 写的是惯例，不是公式。第 8 节末尾至少写一条可以打破的惯例。
- 不写具体作品的角色、台词、镜头。可以在“对标”里列用户认可的参考，只用来对齐感觉。
