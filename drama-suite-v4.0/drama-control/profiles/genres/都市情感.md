# 都市情感

- 类型：叙事方式（现实背景下的情感和人生困境）
- 主要受众与常见平台：受众广泛；短视频平台、短剧平台
- 档案版本与日期：v1，2026-11-13
- 依据：通用的现实题材经验。需要用对标作品和实际数据校准

## 1. 观众承诺

- 核心情绪：共鸣，“这说的就是我”；以及在困境中被理解、被安慰
- 最不能接受的落空：人物和情节不真实；为了冲突而狗血；说教

## 2. 钩子

- 常用开场钩子：一个熟悉的生活困境；一句戳中人心的话；一个平常场景里的裂痕
- 密度：中等，靠情感的积累而不是事件的密度
- 有效的钩子：具体的、有细节的生活处境。无效的钩子：笼统的“压力好大”

## 3. 人物与关系

- 主角类型：普通人，在工作、家庭、感情里遇到困境
- 阻力：现实（钱、时间、身份、家庭）和人物自己的性格
- 张力来源：情感亏欠，以及说不出口的话
- 避免脸谱：没有纯粹的坏人，每个人都有自己的难处

## 4. 节奏与反转

- 走向：积累，然后爆发或释怀
- 反转：多是情感上的，一个人物的另一面被看见
- 需要给足时间：沉默、犹豫、终于说出口的时刻

## 5. 视觉倾向

- 色调：自然，贴近生活，饱和度适中
- 光线：自然光感，实景光源（窗光、台灯、街灯）
- 镜头：生活化的调度，平视为主，克制的运动
- 标志性画面：深夜的独处；城市的街景；家里的餐桌

## 6. 声音倾向

- 音乐：克制，在情绪的高点才进入
- 音效：真实的生活环境声
- 静默：说不出口的时刻

## 7. 集尾钩子

- 常用：一个决定即将做出；一段关系出现转折；一句话没有说完
- 好的集尾：留下情感上的余韵或悬念。差的集尾：硬塞一个狗血事件

## 8. 雷区

| 雷区 | 表现 | 对策 |
|---|---|---|
| 狗血 | 为了冲突加入不真实的情节 | 冲突来自真实的处境和性格 |
| 说教 | 人物在讲道理 | 让人物的选择表达态度，不用台词讲 |
| 表演过度 | 哭喊、咆哮 | 克制的表演更有力量 |
| 细节失真 | 职业、收入、生活方式不符合现实 | 剧本阶段核对现实细节 |

可以打破的惯例：都市情感不一定要压抑，轻松幽默地讲生活困境，同样能引起共鸣。

## 9. 给各模块的提示

| 模块 | 这个题材要特别注意的 |
|---|---|
| 剧本 | 生活细节要真实具体；潜台词比冲突更重要 |
| 导演与视觉开发 | 自然、克制；用色彩讲人物的处境 |
| 资产 | 场景要有生活痕迹；服装符合人物的经济状况 |
| 分镜 | 生活化的调度；克制的表演；反应镜很重要 |
| 剪辑与后期 | 不要剪掉沉默；音乐少而准 |
| 宣发物料 | 标题和封面要有共鸣感，戳中具体的处境 |
