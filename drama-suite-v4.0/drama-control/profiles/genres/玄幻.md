# 玄幻

- 类型：世界观设定（架空的奇幻世界，有力量体系、种族、宗门、秘境），常与升级流叠加
- 主要受众与常见平台：以男性观众为主；短剧平台、视频平台
- 档案版本与日期：v1，2026-11-13
- 依据：通用的玄幻类型经验。和古装仙侠的区别在于更强调力量体系和宏大的世界，东方美学不是必须。需要用对标作品和实际数据校准

## 1. 观众承诺

- 核心情绪：宏大世界的奇观，以及力量的震撼
- 最不能接受的落空：世界观空洞，只有名词没有画面；力量的表现没有气势；画面廉价

## 2. 钩子

- 常用开场钩子：一个宏大的奇观；一场力量的碰撞；主角获得改变命运的机缘
- 密度：中高。世界观的展示可以作为钩子的一部分
- 有效的钩子：奇观和人物的命运连在一起。无效的钩子：大段旁白介绍世界观

## 3. 人物与关系

- 主角类型：命运特殊的人，身负血脉、传承或使命
- 对手：宗门、种族、更高的存在
- 张力来源：力量和地位的不对等；种族和阵营的对立
- 避免脸谱：不同阵营有各自的立场和道理

## 4. 节奏与反转

- 走向：舒展和激烈交替；世界观的展示和人物的冲突交织
- 反转：身世的揭示；世界真相的揭示
- 需要给足时间：奇观的建立镜头；力量碰撞的瞬间

## 5. 视觉倾向

- 色调：按世界观设计，不同地域、种族、阵营各有色调
- 光线：强烈的、有设计感的光；力量用光效表现
- 镜头：大远景和超大远景建立世界；仰拍表现巨物和强者；冲击时的快速推拉
- 标志性画面：巨大的建筑或生物；漫天的光效；宗门大殿

## 6. 声音倾向

- 音乐：宏大的管弦乐或史诗风格
- 音效：力量的音效要厚重，有低频
- 静默：力量爆发之前

## 7. 集尾钩子

- 常用：更强的存在现身；身世之谜露出线索；一场大战即将开始
- 好的集尾：世界在扩大，主角的命运在推进。差的集尾：只抛出一个新名词

## 8. 雷区

| 雷区 | 表现 | 对策 |
|---|---|---|
| 设定堆砌 | 大量名词和旁白介绍世界观 | 通过人物的经历展示世界，一次只给必要的信息 |
| 奇观撑不起 | 大场面生成效果差、廉价 | 选少量能做好的奇观画面，其余用局部和反应表现 |
| 光效喧宾夺主 | 看不清人物 | 光效服务于叙事，留出人物的位置 |
| 力量体系混乱 | 能力随剧情改变 | 在项目设定里写清体系 |

可以打破的惯例：玄幻不一定要宏大，从一个小地方、一个小人物的视角去看宏大世界，常常更有代入感。

## 9. 给各模块的提示

| 模块 | 这个题材要特别注意的 |
|---|---|
| 剧本 | 世界观和力量体系写进项目设定；用人物的经历带出世界 |
| 导演与视觉开发 | 不同地域和阵营的视觉区分；奇观的设计 |
| 资产 | 场景和生物的设计量大，要做预算；种族和阵营的服装要成体系 |
| 分镜 | 奇观镜头少而精；力量碰撞用冲击瞬间和反应表现 |
| 剪辑与后期 | 低频和厚重的音效；光效的音画配合 |
| 宣发物料 | 封面要有宏大的尺度感 |
