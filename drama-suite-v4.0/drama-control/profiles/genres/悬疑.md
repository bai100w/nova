# 悬疑

- 类型：叙事方式（以信息的控制为核心）
- 主要受众与常见平台：受众广泛；短视频平台、短剧平台
- 档案版本与日期：v1，2026-11-13
- 依据：通用的悬疑类型经验。需要用对标作品和实际数据校准

## 1. 观众承诺

- 核心情绪：不安和好奇，以及真相揭开时“原来如此”的满足
- 最不能接受的落空：真相不合逻辑；线索不公平（真相依赖观众不可能知道的信息）；悬念没有回收

## 2. 钩子

- 常用开场钩子：一个反常的画面；一个无法解释的事件；一句让人背后发凉的话
- 密度：每一场都要提出新问题，或让旧问题更尖锐
- 有效的钩子：具体的异常。无效的钩子：模糊的“有什么不对劲”

## 3. 人物与关系

- 主角类型：想弄清真相的人，或被卷进去的普通人
- 对手：隐藏的人或力量，常常就在身边
- 张力来源：信息不对等。谁知道什么，是这个题材的一切
- 避免脸谱：可疑的人不一定是凶手，凶手要有让人信服的动机

## 4. 节奏与反转

- 走向：平静中出现异常，异常越来越多，最后揭开
- 反转：真相的揭示，或对之前理解的颠覆。必须有铺垫，回头看能对上
- 需要给足时间：异常被发现的瞬间；真相揭开后人物的反应

## 5. 视觉倾向

- 色调：低调，冷色为主，低饱和
- 光线：硬光，大面积暗部，光只落在需要的地方
- 镜头：限制观众的视野（遮挡、框中框、主观视点）；背后留白制造不安；长焦的窥视感
- 标志性画面：暗处的轮廓；门缝；倒影；被遮住一半的脸

## 6. 声音倾向

- 音乐：稀疏，长音，低频
- 音效：环境声被放大（钟表、滴水、脚步）；声音先于画面出现
- 静默：异常出现前的一拍；真相揭开的瞬间

## 7. 集尾钩子

- 常用：一个新的线索出现；一个人物的身份被怀疑；危险即将到来
- 好的集尾：提出一个具体的、让人想知道答案的问题。差的集尾：用无关的惊吓结束

## 8. 雷区

| 雷区 | 表现 | 对策 |
|---|---|---|
| 线索不公平 | 真相依赖观众从没见过的信息 | 关键线索要在前面出现过 |
| 靠惊吓不靠悬念 | 突然的声音和画面，没有持续的紧张 | 让观众提前知道危险，替人物着急 |
| 真相不合逻辑 | 为了意外而意外 | 揭开后回头看，每一处都说得通 |
| 画面太暗看不清 | 为了氛围压得太暗 | 暗部保留叙事需要的细节 |

可以打破的惯例：悬疑不一定要冷色调，在温暖明亮的日常里出现的异常，常常更让人不安。

## 9. 给各模块的提示

| 模块 | 这个题材要特别注意的 |
|---|---|
| 剧本 | 设计好信息的释放顺序；线索要公平 |
| 导演与视觉开发 | 视觉母题很重要；控制观众看到什么 |
| 资产 | 关键道具（线索）要单独设计，状态变化要登记 |
| 分镜 | 用景别和构图控制信息；反应和发现的顺序要设计 |
| 剪辑与后期 | 声音先行；静默的使用；不要剪掉悬念需要的停顿 |
| 宣发物料 | 封面用一个具体的异常，不剧透真相 |
