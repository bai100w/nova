# 升级流

- 类型：叙事方式（主角持续变强，逐级挑战更强的对手），常与玄幻、末日、都市异能叠加
- 主要受众与常见平台：以男性观众为主；短剧平台、短视频平台
- 档案版本与日期：v1，2026-11-13
- 依据：通用的升级类型经验。需要用对标作品和实际数据校准

## 1. 观众承诺

- 核心情绪：持续变强的成长感，以及每次突破、越级挑战时的爽感
- 最不能接受的落空：升级没有代价和过程；实力体系混乱；主角停滞太久

## 2. 钩子

- 常用开场钩子：主角最弱的时刻获得机缘（系统、传承、秘籍）；被看不起的人当众突破；一个越级挑战
- 密度：高。每集都要有可见的进步或一次实力展示
- 有效的钩子：主角的弱和他得到的机会形成反差。无效的钩子：主角一开始就很强

## 3. 人物与关系

- 主角类型：起点低、有韧性、有一个变强的理由
- 对手：每个阶段一个更强的对手，等级清楚
- 张力来源：实力的不对等，以及别人对主角实力的误判
- 避免脸谱：对手不只是踏脚石，可以有自己的骄傲和道理

## 4. 节奏与反转

- 走向：受挫、获得、修炼、突破、展示，循环且每轮更大
- 反转：主角的实力超出所有人的预期；隐藏的更高境界
- 需要给足时间：突破的瞬间要有仪式感；旁人震惊的反应

## 5. 视觉倾向

- 色调：随实力提升，主角的视觉更亮、更有光彩
- 光线：突破时的光效；强者出场的逆光和轮廓光
- 镜头：用角度表现实力的变化（从被俯拍到被仰拍）；突破时的升格、环绕
- 标志性画面：境界或等级的可视化（光芒、气场、数值界面）；众人仰望

## 6. 声音倾向

- 音乐：激昂的、递进的；突破时的高潮
- 音效：实力的展示要有分量（气场、冲击）
- 静默：突破之前的一拍

## 7. 集尾钩子

- 常用：更强的对手出现；突破即将完成；主角的实力即将被揭示
- 好的集尾：让观众期待下一次变强。差的集尾：主角突然变弱，没有理由

## 8. 雷区

| 雷区 | 表现 | 对策 |
|---|---|---|
| 实力体系混乱 | 等级和能力随剧情需要改变 | 在项目设定里写清等级和每级的能力 |
| 升级太快没有分量 | 每集都突破，突破变得廉价 | 突破要有代价和积累 |
| 只有数值没有画面 | 靠台词和字卡说“变强了” | 实力的变化要有可见的表现 |
| 战斗场面撑不起 | 打斗生成效果差 | 用冲击瞬间、反应、局部表现，少做连续的打斗过程 |

可以打破的惯例：升级不一定是战力，社会地位、手艺、人心的升级同样能带来爽感。

## 9. 给各模块的提示

| 模块 | 这个题材要特别注意的 |
|---|---|
| 剧本 | 等级体系写进项目设定；每次升级要有代价和展示 |
| 导演与视觉开发 | 等级的视觉表现要成体系（颜色、光效） |
| 资产 | 主角的造型随等级变化，每个阶段登记为一个造型 |
| 分镜 | 角度表现实力；突破的瞬间给足镜头 |
| 剪辑与后期 | 突破的音画节拍；等级界面的包装统一 |
| 宣发物料 | 封面突出主角最强的姿态 |
