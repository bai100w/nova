# 末日

- 类型：世界观设定（灾难、丧尸、天灾、外星入侵等导致的文明崩溃），常与升级流、逆袭复仇叠加
- 主要受众与常见平台：以男性观众为主；短剧平台、短视频平台
- 档案版本与日期：v1，2026-11-13
- 依据：通用的末日和生存类型经验。需要用对标作品和实际数据校准

## 1. 观众承诺

- 核心情绪：绝境求生的紧张，以及在混乱中建立秩序、掌控局面的爽感
- 最不能接受的落空：主角不靠能力和判断，靠运气活下来；末日的威胁不可信；物资和规则前后矛盾

## 2. 钩子

- 常用开场钩子：末日降临的瞬间；主角重生回到末日之前，提前囤货布局；一个极端的生存选择
- 密度：高。每集都要有新的威胁或新的资源
- 有效的钩子：具体的生存危机。无效的钩子：只有场面，没有人物的处境

## 3. 人物与关系

- 主角类型：有先知（重生）、有能力（异能、系统）、或有决断力的人
- 阻力：怪物、天灾、物资短缺，以及比怪物更危险的人
- 张力来源：资源的争夺；信任和背叛
- 避免脸谱：其他幸存者不只是炮灰或拖油瓶，有人性的复杂

## 4. 节奏与反转

- 走向：危机、应对、获得资源或能力、更大的危机
- 反转：盟友的背叛；威胁的真相；主角的隐藏实力
- 需要给足时间：危机来临前的预兆；主角做出决断的瞬间

## 5. 视觉倾向

- 色调：低饱和，废土感；灰、褐、锈色；安全区可以用暖色对比
- 光线：昏暗、浑浊的天光；火光；手电筒
- 镜头：手持的紧张感（在危机中）；大远景表现废墟的尺度；主观视点制造恐惧
- 标志性画面：空荡的城市；囤满物资的仓库；被围困的建筑

## 6. 声音倾向

- 音乐：低沉的电子或工业音色；危机时的紧张节奏
- 音效：环境的压迫感（风、远处的嘶吼、建筑的吱嘎）；怪物和武器的音效要有分量
- 静默：危险靠近时

## 7. 集尾钩子

- 常用：新的威胁出现；队伍里出现内鬼；资源即将耗尽
- 好的集尾：生存压力升级。差的集尾：无理由地让主角陷入危机

## 8. 雷区

| 雷区 | 表现 | 对策 |
|---|---|---|
| 规则混乱 | 怪物的弱点、能力的上限随剧情改变 | 在项目设定里写清规则和代价 |
| 主角太顺 | 没有真正的危险 | 让主角付出代价，失去重要的东西 |
| 血腥过度 | 画面令人不适，违反平台规范 | 用暗示、声音、反应代替直接的血腥画面 |
| 场面撑不起 | 大场面生成效果差 | 用局部和细节表现规模，少做大群戏 |

可以打破的惯例：末日不一定以战斗为核心，一个人在末日里守护一件小事，同样能成立。

## 9. 给各模块的提示

| 模块 | 这个题材要特别注意的 |
|---|---|
| 剧本 | 生存规则写清楚；每集的资源和威胁要有变化 |
| 导演与视觉开发 | 废土质感；安全区和危险区用色彩区分 |
| 资产 | 场景的破败程度和状态变化要登记；武器和物资是关键道具 |
| 分镜 | 大群怪物少做，用局部、声音、反应表现；手持用在危机中 |
| 剪辑与后期 | 声音的压迫感；危机的节奏 |
| 宣发物料 | 封面突出生存危机和主角的决断 |
