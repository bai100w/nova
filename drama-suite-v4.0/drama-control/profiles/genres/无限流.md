# 无限流

- 类型：叙事方式（主角被卷入一个接一个的副本或关卡，每个副本有独立的规则），常与悬疑、末日、玄幻叠加
- 主要受众与常见平台：以男性观众为主；短剧平台、短视频平台
- 档案版本与日期：v1，2026-11-13
- 依据：通用的无限流和规则类型经验。需要用对标作品和实际数据校准

## 1. 观众承诺

- 核心情绪：解谜和闯关的刺激，以及主角利用规则、反制规则的智商爽感
- 最不能接受的落空：规则不清楚，观众无法跟着思考；主角靠运气通关；副本之间重复

## 2. 钩子

- 常用开场钩子：主角突然进入一个陌生的空间，规则出现；违反规则的人当场付出代价；一条看起来矛盾的规则
- 密度：高。每个副本开头就要把规则和危险摆出来
- 有效的钩子：一条让人想弄明白的规则。无效的钩子：只有恐怖氛围，没有规则

## 3. 人物与关系

- 主角类型：冷静、善于观察和推理的人
- 阻力：副本的规则和怪物；其他玩家
- 张力来源：信息不对等（谁看透了规则）；玩家之间的合作和背叛
- 避免脸谱：其他玩家也有自己的推理和策略，不只是送死的

## 4. 节奏与反转

- 走向：进入副本、理解规则、试探、发现规则的漏洞或真相、通关
- 反转：规则的真正含义和表面不同；看起来安全的其实最危险
- 需要给足时间：规则出现的画面（让观众看清）；主角推理出答案的瞬间

## 5. 视觉倾向

- 色调：每个副本一套独立的色调和视觉规则，副本之间有明显区别；主世界或休息区用统一的色调
- 光线：服务于每个副本的氛围
- 镜头：规则出现时给清楚的画面；推理时的特写
- 标志性画面：规则以文字或界面的形式出现；一个看似平常却不对劲的空间

## 6. 声音倾向

- 音乐：每个副本一个主题；推理时的节奏感
- 音效：系统提示音是这个题材的标志
- 静默：违反规则之前

## 7. 集尾钩子

- 常用：新的规则出现；一个玩家违规；通关后进入更难的副本
- 好的集尾：让观众想知道这条规则怎么破。差的集尾：规则还没讲清就结束

## 8. 雷区

| 雷区 | 表现 | 对策 |
|---|---|---|
| 规则看不清 | 规则文字一闪而过，或者太多 | 规则用后期排版清楚呈现，给足阅读时间；一次只给几条 |
| 通关靠运气 | 主角没有推理就过了 | 让观众看到推理的过程和依据 |
| 副本重复 | 每个副本都是同一种套路 | 每个副本换一种规则逻辑和视觉风格 |
| 设定太复杂 | 观众跟不上 | 每个副本的核心规则一句话能说清 |

可以打破的惯例：通关不一定靠破解规则，有时遵守规则、付出代价，是更有力的选择。

## 9. 给各模块的提示

| 模块 | 这个题材要特别注意的 |
|---|---|
| 剧本 | 每个副本的规则单独写清；推理过程要公平，观众能跟上 |
| 导演与视觉开发 | 每个副本一套视觉规则，主世界一套 |
| 资产 | 每个副本的场景是一组新资产，要做预算；规则界面的样式统一 |
| 分镜 | 规则出现的镜头要清楚、停留足够 |
| 剪辑与后期 | 规则文字由后期排版；系统提示音和界面风格统一 |
| 宣发物料 | 封面突出规则和危险 |
