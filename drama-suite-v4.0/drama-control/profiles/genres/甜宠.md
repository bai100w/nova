# 甜宠

- 类型：叙事方式（以情感关系为主线）
- 主要受众与常见平台：以女性观众为主；短剧平台、短视频平台
- 档案版本与日期：v1，2026-11-13
- 依据：通用的言情类型经验。需要用对标作品和实际数据校准

## 1. 观众承诺

- 核心情绪：心动，以及被偏爱、被坚定选择的安全感
- 最不能接受的落空：男女主之间没有化学反应；甜的部分被虐的部分淹没；一方对另一方的好显得不真诚

## 2. 钩子

- 常用开场钩子：意外的亲密接触或近距离；身份反差的初遇（例如以为是普通人，其实是大人物）；契约或误会把两人绑在一起
- 密度：每集至少一个让人心跳的瞬间
- 有效的钩子：两人之间的张力（靠近又不能靠近）。无效的钩子：只有一方单方面的付出

## 3. 人物与关系

- 主角类型：女主有自己的目标和底线，不只是等待被爱；男主外冷内热或表面强势、只对女主温柔
- 阻力：身份差距、误会、第三者、家庭，或两人自己的性格
- 张力来源：情感亏欠和信息不对等（他知道她不知道的，或者反过来）
- 避免脸谱：男主的强势要有分寸和理由，不变成控制；女主的“傻白甜”要有可爱的原因，不变成蠢

## 4. 节奏与反转

- 走向：靠近、被打断、再靠近，一步步加深
- 反转：多是误会的揭开、身份的揭示、心意的确认
- 需要给足时间：两人对视、靠近、说出心意的时刻，不能剪得太碎

## 5. 视觉倾向

- 色调：高调，暖色为主，柔和的粉、橙、米白
- 光线：柔光，轮廓光和逆光营造梦幻感
- 镜头：近景和特写多，双人镜头和过肩镜头多，浅景深
- 标志性画面：两人的近距离，眼神交汇，手的接触

## 6. 声音倾向

- 音乐：轻快或温柔的旋律，心动时刻用单一乐器（钢琴、吉他）
- 音效：心跳声、轻柔的环境声
- 静默：心动的瞬间，音乐短暂停下

## 7. 集尾钩子

- 常用：心意即将说出口时被打断；一方看到另一方和别人在一起；一个意外的亲密举动
- 好的集尾：让观众急着看两人接下来怎样。差的集尾：用狗血的误会硬拆两人

## 8. 雷区

| 雷区 | 表现 | 对策 |
|---|---|---|
| 霸道变控制 | 男主的行为在今天看来是骚扰 | 强势要有边界，尊重女主的意愿 |
| 甜得没有张力 | 两人一直很好，没有阻力 | 保留外部或内部的阻力 |
| 误会拖太久 | 一句话能说清的事拖了好几集 | 误会要有不能说清的理由 |
| 女主没有自己的线 | 女主只围着男主转 | 给女主自己的目标和成长 |

可以打破的惯例：男女主的强弱可以互换，女主强势、男主温柔，同样能兑现被偏爱的承诺。

## 9. 给各模块的提示

| 模块 | 这个题材要特别注意的 |
|---|---|
| 剧本 | 每集至少一个心动瞬间；台词要有来有回的拉扯 |
| 导演与视觉开发 | 两位主角的归属色要搭配好看；整体氛围明亮 |
| 资产 | 主角的颜值和造型是核心卖点；服装要好看且有变化 |
| 分镜 | 心动瞬间给足时间和景别，眼神和手是重点 |
| 剪辑与后期 | 心动瞬间可以放慢节奏；音乐的进入时机很重要 |
| 宣发物料 | 封面用两人的近距离画面 |
