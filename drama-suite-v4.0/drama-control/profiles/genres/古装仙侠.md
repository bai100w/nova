# 古装仙侠

- 类型：世界观设定（古代或架空的东方世界，常有修仙、法术）
- 主要受众与常见平台：受众广泛；短剧平台、视频平台
- 档案版本与日期：v1，2026-11-13
- 依据：通用的古装和仙侠类型经验。需要用对标作品和实际数据校准

## 1. 观众承诺

- 核心情绪：东方美学的奇观，宿命感，以及跨越身份、种族、时间的情感
- 最不能接受的落空：画面廉价，服化道粗糙；世界观的规则混乱；法术和战斗没有气势

## 2. 钩子

- 常用开场钩子：一个奇观画面；一个宿命的相遇；一场危机中的出手
- 密度：中等，可以给世界观的建立留一些时间
- 有效的钩子：奇观加人物的处境。无效的钩子：只有奇观，没有人物

## 3. 人物与关系

- 主角类型：身负使命或秘密的人；跨越身份的恋人
- 对手：权力、宿命、门派、天道
- 张力来源：身份不对等、宿命和情感的冲突
- 避免脸谱：仙人也有私心，反派也有执念

## 4. 节奏与反转

- 走向：可以比现代题材舒展一些，奇观和情感的段落需要时间
- 反转：身份的揭示（前世、真实身份）、宿命的揭示
- 需要给足时间：奇观的建立镜头；离别和重逢

## 5. 视觉倾向

- 色调：按世界观决定，常见的是清冷的青白、浓烈的红金、水墨的黑白灰
- 光线：有设计感的光，仙气用柔光和光晕，魔气用暗和硬光
- 镜头：大远景建立世界的尺度；升降和舒展的运镜；仰拍表现仙人和神兽
- 标志性画面：飘动的衣袂和长发；山水和云海；法术的光效

## 6. 声音倾向

- 音乐：民族乐器（古琴、笛、箫、琵琶）或与之融合的管弦乐
- 音效：法术、兵器的音效要有质感和分量
- 静默：宿命的时刻

## 7. 集尾钩子

- 常用：身份即将揭示；宿命的预言应验；离别的时刻
- 好的集尾：情感和宿命同时推进。差的集尾：只靠一个新的法术或新的敌人

## 8. 雷区

| 雷区 | 表现 | 对策 |
|---|---|---|
| 服化道廉价 | 服装像影楼装，场景像布景 | 资产阶段在服装和场景上多投入，写清年代和质感 |
| 世界观混乱 | 法术和规则随剧情需要随时改变 | 在项目设定里写清规则和代价，剧本遵守 |
| 特效喧宾夺主 | 光效铺满画面，看不清人物 | 特效服务于叙事，留出人物的位置 |
| 台词半文半白 | 古风台词生硬做作 | 台词可以有古意，但要说得出口 |

可以打破的惯例：仙侠不一定都是宏大叙事，小人物在宏大世界里的小故事，常常更动人。

## 9. 给各模块的提示

| 模块 | 这个题材要特别注意的 |
|---|---|
| 剧本 | 世界观的规则写清楚；古风台词要能念 |
| 导演与视觉开发 | 东方美学的色彩和构图；奇观的设计 |
| 资产 | 服装、发饰、兵器、建筑的质感是核心；资产量大，要做预算 |
| 分镜 | 大远景建立世界；动态的衣袂和头发是生成难点 |
| 剪辑与后期 | 音乐和音效的东方质感；法术特效的音画配合 |
| 宣发物料 | 封面要有东方美学的质感 |
