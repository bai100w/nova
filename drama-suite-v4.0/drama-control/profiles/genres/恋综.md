# 恋综

- 类型：叙事方式（借用恋爱综艺的形式讲虚构的情感故事）
- 主要受众与常见平台：以女性观众为主；短视频平台、短剧平台
- 档案版本与日期：v1，2026-11-13
- 依据：通用的恋爱综艺形式和言情类型经验。一个旧项目的流程案例见 `examples/恋综自动流/`，只作参考。需要用对标作品和实际数据校准

## 1. 观众承诺

- 核心情绪：猜测谁喜欢谁的悬念，以及选择揭晓时的心动或心碎
- 最不能接受的落空：人物关系看不清；选择没有铺垫；嘉宾像在演戏，失去“真实感”

## 2. 钩子

- 常用开场钩子：一个暧昧的瞬间被镜头捕捉；一个出人意料的选择；一句采访里的心里话
- 密度：高。每一集都要有新的关系变化
- 有效的钩子：让观众站队、猜测。无效的钩子：关系已经明朗，没有悬念

## 3. 人物与关系

- 主角类型：多位嘉宾，每人有清晰的性格标签和情感目标
- 阻力：其他嘉宾、规则（约会选择、任务）、自己的顾虑
- 张力来源：信息不对等（观众通过采访知道嘉宾的心意，其他嘉宾不知道）；多角关系
- 避免脸谱：每个嘉宾都要有可爱和可理解的一面，不设纯粹的反派

## 4. 节奏与反转

- 走向：日常互动、暗中较劲、选择揭晓，循环推进
- 反转：选择的结果出人意料；采访里的心意和行动相反
- 需要给足时间：选择揭晓前的停顿；被选中或落选的反应

## 5. 视觉倾向

- 色调：明亮、清新，像综艺的质感
- 光线：自然光为主，夜晚的场景用暖色的实景光
- 镜头：观察式的视角（像隐藏摄像机）；采访镜头（单人正面，干净的背景）；大量的反应镜
- 标志性画面：采访间；多人同桌；两人独处被远远拍到

## 6. 声音倾向

- 音乐：轻快的综艺配乐；暧昧时刻用流行情歌风格
- 音效：综艺式的音效（叮、心跳、问号）可以用，但要有节制
- 静默：选择揭晓前

## 7. 集尾钩子

- 常用：选择即将揭晓；某位嘉宾的采访透露意外的心意；新嘉宾加入
- 好的集尾：让观众想猜下一步。差的集尾：用剪辑刻意误导，揭晓后让观众觉得被骗

## 8. 雷区

| 雷区 | 表现 | 对策 |
|---|---|---|
| 人物太多分不清 | 观众记不住谁是谁 | 每个嘉宾的辨识度要高；名条和花字帮助辨认 |
| 关系线混乱 | 观众搞不清谁喜欢谁 | 用采访和关系图（花字）让关系清楚 |
| 太像剧 | 失去综艺的观察感 | 保留采访、观察视角、综艺包装 |
| 包装过度 | 花字和音效铺满 | 包装服务于关系的变化 |

可以打破的惯例：恋综不一定以配对成功收尾，一个人选择离开、选择自己，同样可以是好的结局。

## 9. 给各模块的提示

| 模块 | 这个题材要特别注意的 |
|---|---|
| 剧本 | 每集的关系变化要清楚；采访台词要像真人说话 |
| 导演与视觉开发 | 综艺质感；观察式的视角 |
| 资产 | 嘉宾多，辨识度是第一要务；采访间是常用场景 |
| 分镜 | 大量反应镜；采访镜头和观察镜头交替 |
| 剪辑与后期 | 名条、花字、综艺音效是这个题材的语言，但要克制 |
| 宣发物料 | 封面突出关系的悬念 |
