# 表演与声音概念

## 表演基调

表演基调规定全片的人物怎么演。它交给分镜模块，由分镜写进每个镜头的表演指示。没有统一的基调，同一个人物在不同镜头里会一会儿内敛一会儿夸张。

### 全片层面

**写实程度。** 在一条刻度上选位置，并说明理由：

- 生活化：像偷拍到的真人，台词有停顿、有不完整的句子。
- 戏剧化：情绪更清楚、更集中，但仍然可信。多数短剧在这里。
- 风格化：有意夸张，表情和肢体放大。喜剧、部分动画和漫剧。

形态档案第 5 节给了这个形态可行的范围。真人短剧里过度夸张容易让脸变形、显得假；2D 动画和漫剧则需要一定的夸张，画面才立得住。

**幅度。** 默认的表情和肢体幅度有多大。一条通用的经验是：默认用小的，把大的留给最高点。全片都在用力，最高点就没有余地了。

**节奏。** 人物说话和反应的速度。快节奏的题材反应快、抢话；压抑的题材允许长停顿。停顿是表演的一部分，要在分镜里留出时间。

**情绪最高点怎么演。** 提前想好全片最重的那一刻用什么方式呈现。爆发是一种，彻底的安静是另一种，后者常常更有力。

### 人物层面

每个主要人物写一组：

| 项 | 内容 |
|---|---|
| 表演关键词 | 两三个，例如绷着、慢半拍、笑不到眼睛里 |
| 身体习惯 | 站姿、手放哪里、紧张时的小动作 |
| 眼神 | 直视还是回避，看人还是看物 |
| 情绪怎么漏出来 | 这个人不直接表达时，情绪从哪里露出来 |
| 随人物弧的变化 | 开始和结束时，上面几项有什么不同 |

这些内容与剧本模块人物小传里的“出场动作”“说话习惯”保持一致，在其基础上细化。

### 给生成的提示

- 微表情和眼神比大幅度的表情更容易做好，也更耐看。
- 情绪尽量落在可见的动作上：呼吸、吞咽、手的动作、视线的移动。
- 反应和说话同样重要。听的人的脸，常常是这场戏真正的内容。

## 声音概念

声音概念规定全片听起来是什么样。它交给资产模块（声线）、分镜模块（声音设计）和剪辑模块（音乐、音效、混音）。

用户对字幕、背景音乐、音效、环境声的明确决定优先于这里的任何设计。项目规定不用背景音乐，声音概念就在这个前提下做。

### 声音的四层

| 层 | 要决定的事 |
|---|---|
| 人声 | 对白、旁白、内心独白各自怎么处理。旁白是贴近耳边还是有距离感，内心独白和对白在听感上怎么区分 |
| 环境声 | 每个主要场景的底色。安静的房间也有声音：空调、远处的车、钟。环境声让空间可信 |
| 音效 | 动作和物件的声音。哪些要突出，哪些可以省略 |
| 音乐 | 风格、乐器、情绪方向，以及在哪里进、在哪里出 |

### 音乐

- **风格和乐器。** 写具体：稀疏的钢琴单音，还是铺满的弦乐；合成器，还是原声乐器。对得上导演阐述的基调。
- **进出点。** 对照情绪曲线，标出音乐在哪些段落出现。音乐进来的那一刻本身就是一次强调。
- **主题动机。** 可以为主角或核心关系设计一个短小的旋律或音色，在关键处重复和变化。
- **不用音乐的地方。** 明确写出来。全程铺满音乐，音乐就失去了作用。

### 标志性声音

一个反复出现、有含义的声音，相当于声音上的母题。可以是门禁的提示音、一段口哨、某种铃声。写清它是什么、代表什么、在哪几处出现。

### 静默

把声音拿掉，是声音设计里最有力的手段之一。在阐述里指定一到两处：最高点之前的一拍、反转落下的那一刻。静默需要前后的声音来衬托，所以它的前一段要有足够的声音。

静默不等于完全没有声音，通常保留极轻的环境声或一个持续的低音。这和项目规定的“无声段落”是两回事，分开记录。

### 响度和动态

写倾向即可，具体数值在后期按发布平台的要求确定：全片是平稳的，还是有明显的强弱对比；对白永远优先能听清。

## 自查

- 表演的写实程度和幅度在形态档案允许的范围内。
- 每个主要人物有表演关键词和身体习惯，并且彼此不同。
- 最高点的表演方式已经想好。
- 声音四层都有决定。
- 音乐的进出点对得上情绪曲线，写了不用音乐的地方。
- 没有违反用户对字幕、音乐、音效的明确决定。
