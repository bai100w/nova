# 导演阐述

导演阐述是一页纸，写给后面所有环节看。它不描述剧情，只说明这部片子要给观众什么感受，以及靠什么手段做到。

## 结构

### 1. 立意

一两句话：这个故事真正在讲什么。不是剧情梗概，是剧情底下的那层意思。

- 梗概：“被顶替身份的女孩夺回自己的名字。”
- 立意：“一个人被所有人否认时，靠什么确认自己是谁。”

立意决定取舍。两个同样好看的镜头，选更贴近立意的那个。

### 2. 观众的感受

按段落写希望观众有什么感受，以及感受怎么变化。对照节拍表来写。

例：“开场是困惑和一点不安；中段是被困住的窒息感，越来越紧；反转处是后背发凉；结尾不给解脱，留一口气悬着。”

这一节要对得上题材档案的观众承诺。对不上时二选一：改阐述，或写明这部片子有意偏离题材惯例以及理由。

### 3. 基调

三到五个关键词，每个词配一个它的反面，用“是什么，不是什么”来写。只写正面的词，每个人的理解都不一样。

| 是 | 不是 |
|---|---|
| 克制的冷 | 阴森恐怖 |
| 日常里的异样 | 超现实的奇观 |
| 安静的压迫 | 吵闹的惊吓 |

### 4. 视听策略

三到五条贯穿全片的做法。每条写成“做什么，为了什么”，并且具体到可以执行。

- 空泛：“用光影营造悬疑氛围。”
- 具体：“主角始终处在画面里最暗的区域，光打在她周围的人和物上。她被这个环境排除在外，这是立意在画面上的样子。”

再写一条破例：全片守着的某条规则，在哪个时刻打破，为什么。

例：“全片不用手持，镜头始终稳定而冷静。只有她冲出大楼的那一个镜头用手持，这是她第一次主动行动。”

### 5. 对标

用户认可的参考，或学习模块的参考卡。每个参考只写借鉴哪一点：它的光、它的节奏、它的色彩。对标是为了对齐感觉，不复制任何具体内容。

没有参考时不硬编。可以请用户给两三个喜欢的和不喜欢的例子，反面例子往往更有用。

## 情绪曲线

情绪曲线把节拍表的强度一栏画成全集的起伏，供分镜分配镜头、剪辑安排节奏、音乐安排进出。

**做法：**

1. 取节拍表里每个节拍的强度和时长。
2. 给每个节拍加一个情绪色彩，例如紧张、温暖、压抑、释放、荒诞。
3. 检查形状，按下面的要点调整。调整意味着回头和剧本模块一起改节拍，不是只改这张图。

**检查要点：**

- 有一个明确的最高点，位置一般在后段。
- 最高点之前有一段相对的低谷。没有低，就没有高。
- 没有连续三个以上强度相同的节拍。平是比低更大的问题。
- 中片和长片有气口：强度明显降下来的时刻，时间不用长。
- 开场强度不低于中等。
- 相邻节拍的情绪色彩有变化。同一种紧张持续太久，观众会麻木。

**记录方式：** 用表格，不需要画图。

| 节拍 | 时间段 | 强度 | 情绪色彩 | 视听上怎么配合 |
|---|---|---|---|---|
| | | | | |

最后一栏是这张表的价值所在：强度高的地方镜头更碎还是更长，音乐进还是出，色彩怎么变。它把抽象的起伏变成各环节的具体指令。

## 写法要求

- 一页以内。写不进一页，说明还没想清楚。
- 每句话都能被下游执行或检查。删掉所有只是形容的句子。
- 不复述剧情。
- 先请用户确认立意和基调这两节，再展开其余部分。

## 对照示例

不合格：

> 本片采用电影级的视听语言，通过精致的光影和富有张力的镜头，营造出悬疑紧张的氛围，带给观众沉浸式的观看体验。色彩上运用冷暖对比，突出人物情绪。

问题：这段话放在任何一部悬疑片上都成立，所以它没有提供任何信息。资产和分镜拿到它，仍然不知道该做什么。

合格的写法见上面各节的例子：有立意，有是与不是，有做什么与为了什么，有一处破例。
