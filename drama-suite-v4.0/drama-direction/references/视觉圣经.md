# 视觉圣经

视觉圣经把导演阐述翻译成画面上的具体规定。资产模块照它设计，分镜模块照它设计每个镜头，剪辑模块照它调色。

先看形态档案第 1 节，确定用哪一套语言：

- **物理摄影版**（真人短剧、3DCG 动画）：用摄影的概念描述画面，写第 1、2、3A、4、5、6 节。
- **画面设计版**（2D 动画、漫剧）：用美术和构图的概念描述画面，写第 1、2、3B、4、5、6 节。

## 1. 色彩

色彩是观众最先感到、最难说清的东西，也是统一全片最有效的手段。

**主色盘。** 选三到五个颜色，写清各自的角色：

- 主导色：占画面最多的颜色，定下全片的冷暖和轻重。
- 辅助色：与主导色协调，用来区分场景或阵营。
- 强调色：面积很小，只留给最重要的东西，例如关键道具、主角的某件衣物、危险的信号。

强调色的力量来自稀少。到处都用，就不再是强调。

**色彩归属。** 把颜色分配给人物、阵营或情绪状态。观众不会意识到，但会感到一致。例如主角始终带一点暖色，她所处的环境是冷的；随着她被环境吞没，她身上的暖色逐场减少。

**色彩脚本。** 对照情绪曲线，按段落写色彩怎么变：

| 段落 | 主导色 | 饱和度 | 明暗 | 冷暖关系 | 为什么 |
|---|---|---|---|---|---|
| | | | | | |

色彩的变化要跟着故事走。全片一个色调是统一，但也浪费了一种叙事手段。

**肤色。** 真人和偏写实的 3D，不论整体色调多冷多暖，人物肤色要保持在自然可信的范围内。这一条写进圣经，调色时也照此执行。

## 2. 影调与光线

**影调。** 整体偏亮还是偏暗，反差大还是小。

- 高调：画面明亮，阴影少而浅。轻松、甜、干净。
- 低调：大面积暗部，光只落在需要的地方。悬疑、压抑、危险。
- 反差大，戏剧性强；反差小，柔和、日常。

**光的质地。** 硬光轮廓清楚、阴影锐利，显得冷峻、有力；柔光过渡平缓，显得温和、亲近。写明全片的倾向，以及哪些场合例外。

**光的方向与动机。** 光从哪里来，要有画面里说得通的来源：窗、灯、屏幕、火。有来源的光让画面可信，资产模块设计场景时要把这些光源放进去。

- 正面光平，侧光有立体感，逆光出轮廓和氛围，顶光和底光让人不安。

**光比。** 人物脸上亮部和暗部的差距。差距小，人物坦然、亲切；差距大，人物有隐藏、有矛盾。可以让光比随人物的处境变化。

**色温。** 冷暖光的搭配是最常用的对比：室内暖光对窗外冷光，屏幕冷光对台灯暖光。写明全片的冷暖策略。

**按场景写光线设计：** 每个主要场景的时间段、主要光源、影调、冷暖。这部分直接进入画面预设表。

## 3A. 镜头规则（物理摄影版）

写三到五条全片遵守的规则，加一到两处破例。每条写明为什么。可以从这些方面选：

**焦段倾向。**

- 广角：空间感强，靠近人物时有压迫和变形，人与环境的关系清楚。
- 标准焦段：接近人眼，平实、客观。
- 长焦：压缩空间，背景虚化，人物被从环境里拎出来，有窥视和疏离感。

**机位高度。** 平视是平等；俯拍让人物显得弱小或被审视；仰拍让人物显得强大或有威胁。

**景深。** 浅景深把注意力锁在一个人身上，把他和环境隔开；深景深让前后景同时说话。

**运动。** 稳定的镜头冷静、克制；缓慢的推近积累压力；手持带来不安和在场感；横移跟随带来流动。写明全片的默认方式，以及什么情况下才允许运动。运动要有动机：跟着人物动，或跟着情绪的变化动。

**构图。** 对称显得庄重、受控或诡异；偏置加留白显得孤立、有悬念；前景遮挡带来窥视感；框中框把人物困住。

**竖屏。** 画幅是竖的时候，纵向的层次比横向的更重要：前景、人物、背景上下或前后排布。双人戏靠前后关系和切镜，不靠左右并排。

## 3B. 画面规则（画面设计版）

2D 动画和漫剧没有真实的摄影机，画面由画法和构图决定。同样写三到五条规则和一到两处破例。

**线条。** 粗细、是否有变化、勾线是干净还是带手绘的抖动。线条是画风里最容易被认出来的部分。

**上色。** 平涂、赛璐璐式的分块阴影、厚涂、水彩质感。阴影分几层，高光怎么处理。

**背景。** 与人物同样精细，还是简化以突出人物；写实还是概括。背景和人物的风格差距要在可控范围内。

**构图与分格。** 画面里人物占多大，留白多少，是否使用分格、斜切、出框。漫剧尤其依赖构图本身的力量，因为画面动得少。

**帧感。** 动作是流畅的还是有意保留停顿感，是否使用定格。

**画面上的运动。** 在静止或少动的画面上做推、拉、摇、移，以及前中后景分层移动造成的纵深感。写明默认的速度和幅度，以及转场的方式。

**效果表现。** 速度线、冲击帧、光效、情绪符号。用还是不用，用到什么程度。

## 4. 质感

画面摸上去是什么感觉。

- 真人：干净的数字感，还是带颗粒的胶片感；锐利还是柔和。
- 3DCG：写实的材质和光照，还是卡通化的渲染；材质的精细程度。
- 2D 和漫剧：纸张或笔触的纹理，颜色是否有不均匀的手工感。

再写三到五个材质关键词，交给资产模块，例如磨砂玻璃、旧木头、潮湿的水泥。

## 5. 视觉母题

一个反复出现的意象、构图或颜色，每次出现时含义有所推进。它把分散的场景串起来。

写清：母题是什么，它代表什么，计划在哪几处出现，最后一次出现时有什么不同。

例：玻璃上的倒影。第一次只是画面的装饰；中段倒影和本人的动作开始有一点不同步；结尾倒影没有跟着她抬头。

母题最多两个。再多，观众记不住。

## 6. 参考板

用户提供或认可的参考图、参考片，以及学习模块的参考卡。每条写明借鉴它的哪一点。

参考用来对齐感觉，不复制具体的构图、角色或标志性画面。没有参考时留空，不凭印象描述别人的作品。

## 画面预设表

把上面的规定落到每个场景，一个场景一套预设，用 [画面预设表模板](../templates/画面预设表模板.md)。分镜阶段每个镜头引用预设编号，只写与预设不同的地方。这样全片的一致性靠预设保证，不靠每个镜头各自重复描述。

预设里的数值是设计意图。模型能不能执行，由生成模块按适配卡处理，并在生成后与实际效果分开记录。

## 自查

- 每一条规定都答得出为什么，并且能追到导演阐述。
- 资产模块看了知道场景里该放什么光源、人物该用什么颜色。
- 分镜模块看了知道默认怎么拍、什么时候破例。
- 色彩脚本跟着情绪曲线在变。
- 规则不超过五条，母题不超过两个。
- 没有出现“电影感”“高级感”这类无法执行的词。
