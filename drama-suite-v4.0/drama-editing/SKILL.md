# 剪辑与后期

剪辑的首要任务不是把素材做热闹，而是让观众在每一次切换后更清楚地感到：事情变了，人物被击中了，或者下一件事马上要发生。

这个模块在流程里出现两次：付费生成之前，按档位需要用脚本生成文字卡预演片；生成之后做成片。

## 开工

1. 读 [共用规则](../drama-control/references/共用规则.md)。
2. 从项目索引读：确认台词表、分镜、导演阐述与情绪曲线、声音概念、色彩脚本、影像与声音参数（画幅、帧率、字幕开关与语言、音乐和环境声的许可、发布平台）、制作状态、审片记录。
3. 只用实际可打开、审片结论为通过、可用部分或可后期修复的素材。生成成功、文件名好看、旧版本，都不等于可剪。

## 任务

| 任务 | 做法 |
|---|---|
| 生成文字卡预演片 | [动态预演组装](references/动态预演组装.md)，运行 `scripts/build_animatic.py` |
| 剪辑成片 | 下面的工作顺序 |
| 学习已有工程 | [草稿学习](references/草稿学习.md)，用草稿学习记录模板 |
| 完整 AI 片段的二次包装 | [悬念收尾](references/悬念收尾.md) |
| 终检 | [终检清单](references/终检清单.md)，由独立评审执行 |

## 剪辑成片的工作顺序

1. **登记可用带。** 每个素材完整看一遍，写下可用的时间段和不可用的原因。审片记录已经写了的直接用，有疑问的重新看。见 [剪辑逻辑](references/剪辑逻辑.md)。
2. **写剪辑决策单。** 用 [剪辑决策单模板](templates/剪辑决策单模板.md)。先排全片的情绪和强弱，再做逐镜的决定，最后设计重点节点。
   - 入点出点、反应、动作：[剪辑逻辑](references/剪辑逻辑.md)
   - 节奏、转场、放大缩小：[节奏与转场](references/节奏与转场.md)
   - 重点节点的音画字配合：[音画节拍设计](references/音画节拍设计.md)
   - 对白、音乐、音效、混音：[声音与音乐](references/声音与音乐.md)
   - 字幕、花字、片尾：[字幕与包装](references/字幕与包装.md)
   - 调色：[调色](references/调色.md)
3. **执行。** 剪辑决策单先给用户看，已有制作授权的按授权范围执行。用什么工具执行见 [执行适配](references/执行适配.md)。
4. **自检与评审。** 按 [评分表与反模式](references/评分表与反模式.md) 评分，按终检清单自查，再交独立评审做终检。

## 精剪要覆盖的六项

用户要求精剪，或流程档位是标准档及以上时，剪辑决策单要覆盖：音乐选段与情绪走向、背景音乐的进退、音效事件、画面冲击、字幕、花字。某一项不用，写明剧情上的原因。只交一张镜头拼接表或一份曲名清单不算精剪。

## 不可跨越的边界

- 剪辑可以删、缩、换镜和加后期包装。不能改人物动机、确认台词、声线、字幕语言或上游镜头的职责。问题回交剧本、资产、分镜或生成模块。
- 用后期遮掩缺资产、缺镜头的问题，只能作为临时处理并如实登记，不能当作解决。
- 背景音乐、音效、字体登记来源和授权状态。没有明确可用权利的，只写音乐方向和 cue，不下载、不嵌入、不声称可以发布。
- 默认用硬切。J-cut、L-cut、叠化、音效、花字、放大，都要服务于写明的剧情节点。不把每个切点、每个词都做成动效。
- 不猜测剪辑软件里特效、转场、花字的编号。需要时查到真实的编号，查不到就标待选。
- 项目自己的字幕开关、语言、画幅、音乐与环境声许可、安全区，优先于这里的任何建议。

## 完成标准

剪辑决策单的每一段都能追溯到真实素材；重点节点可以按时间和参数执行：音乐有可用的选段，音效有峰值位置，画面有运动曲线，文字有入场、停留、退场；强弱和留白有叙事依据；成片与决策单一致。渲染成功不等于质量通过。
