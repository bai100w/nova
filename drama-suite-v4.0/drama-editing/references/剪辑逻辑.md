# 剪辑逻辑

## 先判断素材能不能用

每个来源片段都完整看一遍，先写可用带，再选剪辑点。生成素材常见的不可用部分包括：开头尚未稳定的站姿或视线、人物/道具漂移、动作不自然回弹、口型提前或滞后、重复表演、终帧闪白或重置。不要因镜头“基本能看”而把缺陷裁进成片。

可用带记录格式：`源文件 / 可用 01.20--04.80 / 不能用 00.00--01.20：人物刚落位；04.80 后：手部漂移`。没有实际查看时写“未核验”，不可臆测秒数。

## 入点和出点

| 剪辑问题 | 默认取法 | 禁止取法 |
|---|---|---|
| 行动开始 | 在触发动作或可读停顿前少量进入 | 从动作已经完成后才突然出现 |
| 台词 | 保留完整发音、必要呼吸和对方反应 | 切断词头、词尾、情绪停顿或口型 |
| 信息揭示 | 让观众先看见关键物/表情，再给反应 | 用解释性花字代替可见信息 |
| 情绪余波 | 信息落定后留一小段真实反应 | 为了加速把余波全部抽空 |
| 生成缺陷 | 在缺陷开始前退出 | 用转场、特效或音效遮住已失真的画面 |

每一个 `CUT-` 只写一个主要叙事任务：推进行动、让反应落地、揭示信息、建立空间、压缩时间或收束情绪。若一段没有新信息、新动作或新情绪，删掉它比加特效更有效。

## 反应、动作与空间

- 有一句话改变了对方的处境，优先给对方一个可读反应；不要只在说话人脸上停到台词结束。
- 手、眼神、道具、开门、落座、转身等关键动作，尽量在动作过程内接镜；跨镜前后要保留手性、持物、视线、站位与光线连续性。
- 同场对白至少保留一个交代两人位置和关键物位置的空间锚点。纯正反打不足以维持物理可信度。
- 需要遮掩生成差异时，优先选择剧情本来就成立的反应、手部、道具、门框/前景遮挡或环境细节；不能为遮瑕凭空插入不相干空镜。

## 剪辑单的取舍语言

写可验证的画面事实，而不是“这里节奏需要快”。

好：`入点=她抬眼前的吸气被保留；出点=他握住她的手后，眼神停顿完成。`

不好：`入点=节奏更好；出点=感觉差不多。`
