# 执行适配

剪辑模块负责剪辑的决定。把决定变成工程文件和成片，取决于环境里有什么工具。先确认实际可用的工具，再选方式，不假设工具存在。

| 环境 | 方式 |
|---|---|
| 有剪映草稿工具（例如 `jianying-editor` skill） | 按下文“剪映草稿”一节建立草稿 |
| 有其他可用的剪辑工具或脚本（例如 FFmpeg） | 用它实现剪辑决策单里能实现的部分，其余标待人工处理 |
| 没有可用的剪辑工具 | 交付剪辑决策单，由用户在自己的剪辑软件里照做 |

三种方式交付的剪辑决策单相同。工具只决定由谁来执行。

## 交接前的最小清单

1. 剪辑决策单：每个切点都有真实的来源、可用带、入出点和理由；重点节点有音画字的配合规格。
2. 项目配置：画幅、帧率、字幕和花字的开关、音频的许可、导出路径、发布平台的安全区。
3. 已授权的素材：视频、对白、背景音乐、环境声、音效、字体和花字样式的路径或真实的平台编号。
4. 轨道规划：画面、对白、环境、音乐、音效、字幕、花字和信息卡分别命名。音乐不放进视频轨。

## 剪映草稿

调用已有的剪映工具 skill，遵守它关于草稿、素材、文字、关键帧、特效、声音和导出的规则。

- 业务脚本和检查输出放在项目目录里，不写进任何 skill 的目录。
- 工程的宽高和帧率按项目配置。改变素材画幅时，先写明裁切、留白还是重新构图。
- 使用的接口以工具实际支持的为准，执行前确认方法存在。
- 平台的花字模板、转场、滤镜、特效，先通过工具的素材检索取得真实编号。自制的文字动画记录字体、样式和实际的关键帧。不猜编号，不把伪代码说成已执行。
- 关键帧的时间、起止、缩放幅度和安全区与剪辑决策单一致。不是每一段都需要关键帧。
- 先生成草稿，检查视频轨、音频轨、字幕轨和保存结果。已授权导出成片的继续导出，只授权草稿的交付草稿。
- 导出后检查：文件存在，画幅和帧率，时长，首帧和尾帧，声音。

## 手动执行

交给用户的剪辑决策单要能直接照做：

- 每个切点写清素材文件、源入点、源出点、时间线位置。
- 时间统一用一种单位，注明帧率。
- 关键帧、字幕、花字、音效的时间相对于时间线写。
- 需要特定效果的，写效果要达到的样子，并注明“请在你的软件里选择相近的效果”，不编造某个软件里的效果名称。

## 失败处理

工程保存成功不代表剪辑正确。接口、特效或导出失败时，保留脚本和工程的当前状态，报告失败的步骤、实际的错误、受影响的切点和还没完成的部分。不手工猜写工程文件，不反复覆盖原工程来掩盖失败。
