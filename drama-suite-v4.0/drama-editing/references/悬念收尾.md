# 悬念收尾：完整 AI 片段的声音与包装

适用于原片已经包含完整动作、人物关系和镜头切换，需要强化理解与悬念的剪辑任务。下面是可选的操作逻辑，一个旧项目的实测数值见 `examples/剪辑模块旧资料/人参案例节拍表.md`。

## 先决定保留什么

将原片和输出按画面内容对齐。若叙事镜头已经成立，保留动作和对白完整性；按转折定位需要增强的几个节点。不要为体现“剪辑量”把每段重新切碎。源视频内已有的景别变化、推近、物件特写不可登记成新增后期技巧。

## 可选模块

| 触发条件 | 可执行操作 | 预期作用 | 不适用情况 |
|---|---|---|---|
| 原声的对白与背景难以分别控制 | 在副本拆分/分离人声和背景；确认两层内容与同步，对白优先，背景保持空间感 | 让声音控制独立，不必整体压低有用对白 | 源声干净且无需调整，或分离产生明显水声/金属伪影 |
| 关键道具显露，需要观众看清异常细节 | 在该局部片段做有理由的裁切/放大，保留完整道具和手部因果；与原片并排检查 | 把注意力集中到信息载体 | 原片近景已够清楚、放大后糊掉或裁断关键部位 |
| 物件显露、阻止动作、危险出现 | 建一个事件 cue：触发动作、音效入点、峰值落点、尾巴、对白避让；允许分工明确的声音层与画面/花字合击 | 让注意力与剧情变化同步 | 纯粹因为换镜或素材库音效好听 |
| 后段人物意识到危险 | 先铺克制氛围，再在反应/揭示处加入短冲击或转场声；句中让位，句后承接 | 由环境紧张推进到角色反应 | 全片已经持续很满、或项目禁止 BGM/额外环境声 |
| 结尾存在一个未解决的发现 | 保留最后一句及反应；仅必要时使用一次短聚焦/抖动强化，检查人脸和字幕 | 把结尾落在“意识到异常” | 特效遮住表演、加重生成缺陷、或源片已经有同类效果 |
| 最后反应太快、需要收尾 | 有依据地延长末帧/末段，渐黑后进入简短片名/署名卡；音频尾巴单独处理 | 让悬念有停顿，让主体叙事与片尾分开 | 用户只要无包装成片，或连续剧需要直接接下一镜 |
| 受众需要另一种语言理解对白 | 根据确认文本做原语言＋译文的两行字幕，按句对齐，跨镜头的句子保留语义连续 | 降低理解成本 | 用户要求无字幕或单语；不能照抄样片语言偏好 |

这些是操作建议，不能由缓存文件或音效名称推断成已完成的操作。确认拆音/定格/特效类型仍须当前工程面板或原片对照。

## 悬念结尾的具体执行顺序

1. 写出未解信息及最后一句原文，标出最后一个有效反应帧。
2. 决定原速收尾、延长静帧或保留运动。定格前检查脸、手、口型；不要冻结半个字。视频有瑕疵时可选干净帧，不能把漂移当作悬念。
3. 按剧情需要安排“氛围进入 → 异常信息 → 反应重音 → 收尾留白”。音乐可先于画面转折进入；旧曲与新底床是否交叠依据乐句和实际混音决定，每项均可省略。
4. 若采用聚焦/抖动，先查实际效果 ID，只做一个局部节点；观察缩放、失焦和字幕是否一起抖坏。不抄未读取的强度数值。
5. 若采用渐黑和署名卡，设定各自入出点，检查全黑间隔是否有意，字卡有足够阅读时间；声音可跨过渐黑，但最终淡出避免硬截。

## 声音与字幕验收

把“分层原声”“BGM”“剧情音效”分开登记。先确认原视频原声没有和分离声轨重复播放，再检查声像、对白可懂度、转折词是否被音效遮挡。测量导出 integrated loudness 和 true peak；真峰值超出输出上限时先处理整体增益或峰值，再导出重测，不能照搬参考的音量数值。

字幕需要逐句校对识别和翻译。样片自动识别出的英文语法、遗漏或生硬译法不是风格规则。双语字幕以项目安全区与主要动作位置决定排版，不照抄固定坐标。

## 实证如何使用

旧项目案例中核实过的分离声轨分工、音乐交接、局部快推慢推、字幕与片尾动画，参数只保存在案例库的节拍表里，不作为默认值。借鉴时按当前素材重新测量；不得用波形或缓存名称替代试听。
