# 动态预演组装

动态预演补上纸面预演最缺的一样东西：真实的时间感。纸上写 3 秒和实际看 3 秒，感受差别很大。

它建立在纸面预演之上，不替代纸面预演。是否要做由流程档位决定，见分镜模块的 [分包与预演包](../../drama-storyboard/references/分包与预演包.md)。

## 文字卡预演片

用脚本从分镜模块交来的预演清单自动生成，不需要手工剪：

```
python scripts/build_animatic.py <预演清单.csv> --out <预演.mp4> [--size 720x1280] [--bgm <临时音乐>] [--font <中文字体>]
```

需要 Python 和 FFmpeg。脚本按清单逐镜生成画面：

- 清单的“图片”列有关键帧时，用图片；没有时，用文字卡显示镜号、景别、画面描述。
- 台词显示在画面下方。
- “音频”列有临时配音时，放进对应镜头；没有时，这一镜是静音，台词只显示文字。
- 给了临时音乐时，混在底下。

每一镜的时长严格按清单。时长不合适是要发现的问题，不是要悄悄修正的问题。

同时会输出一份纸面预演摘要，和分镜模块用 `--check-only` 得到的是同一份。

**临时配音：** 用配音模型或系统自带的语音合成快速生成，不要求最终声线，音质无所谓，只用来判断语速和节奏。

**临时音乐：** 按声音概念的进出点选一段，只用于判断节奏，标明“临时”，不进入成片，不需要处理授权。

**没有 FFmpeg 的环境：** 只做纸面预演，在关卡记录里注明“未做文字卡预演片”。不要为了做预演片去手工剪辑，那就失去了低成本的意义。

## 看预演片时检查什么

只看纸面预演判断不了的东西：

| 问题 | 怎么看 |
|---|---|
| 时间感 | 有没有哪一镜明显太长、让人等，或太短、看不清 |
| 节奏 | 连起来看，有没有拖沓的段落，最高点之前的积累够不够 |
| 台词 | 有配音时，语速是否自然，台词之间的停顿是否合适 |
| 钩子 | 前几秒看完，想不想继续看 |

第一遍像观众一样看，只记感受；第二遍对照纸面预演摘要，看问题是否已经解决。

## 输出

- 预演片
- 新发现的问题，补进纸面预演摘要：每个问题对应的镜号、修改建议、归属模块

问题交回分镜模块修改。修改后改预演清单，重新运行脚本即可，几乎不花时间。

## 预演不是粗剪

预演阶段不做精细的剪辑决定：不选音乐的具体段落，不设计花字，不做调色。这些等真实素材到了再做。
