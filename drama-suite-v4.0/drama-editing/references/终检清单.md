# 终检清单

终检是发布前的最后一道关卡，由独立评审执行：另开一个会话或子代理，只给它成片、本清单、确认台词表、分镜和项目配置，不给剪辑过程的讨论。环境不支持独立评审时，按清单自查并在关卡记录里注明。做法见 [质量评审规范](../../drama-control/references/质量评审规范.md)。

每一项写“通过”“需返修”或“未核验”，并附时间码作为证据。没看到、没听到的写“未核验”。有未核验项的终检不能记为通过。

## 1. 叙事

- [ ] 开场尽快呈现人物、问题或情绪张力，没有用无关的花字和音乐遮住慢开场。
- [ ] 只看成片能看懂：谁、在哪、想要什么、发生了什么变化。
- [ ] 钩子、转折、结尾都落了地。
- [ ] 每个切点都能解释为信息、动作、反应、空间、时间或情绪的变化。
- [ ] 删掉的镜头所承载的信息，有别的镜头接住。接不住的回上游，不假装剪辑能修剧本。

## 2. 台词

- [ ] 确认台词逐句在，顺序正确，没有改写。
- [ ] 说话人正确，声线是指定的那一个。
- [ ] 字头、字尾、呼吸没有被切掉。
- [ ] J-cut 和 L-cut 里仍能分清是谁在说。

## 3. 一致性

- [ ] 人脸在全片各镜之间一致。
- [ ] 服装、道具、比例在全片一致。
- [ ] 人物的位置、视线、持物在切点前后连得上。
- [ ] 抽查首帧、每一处换场、每个高风险镜头、尾帧：没有变脸、漂移、闪烁、画面重置。

## 4. 声音

- [ ] 对白在手机外放下清楚。
- [ ] 背景音乐不吞词，音效不抢关键字。
- [ ] 切点没有可以听出来的噪声跳变。
- [ ] 原视频的原声和分离出来的声轨没有重复叠加；分离的结果同步、没有明显的伪影。
- [ ] 重点节点的音效，实际峰值落在动作或关键词上，不只是文件起点对齐。
- [ ] 项目禁止的声音层确实不存在。
- [ ] 综合响度和真峰值实测，符合项目配置的发布要求。超限的处理后重新导出、重新测量。测量合格不能代替实际回听。

## 5. 画面

- [ ] 镜头之间的颜色和亮度连得上，肤色自然。
- [ ] 全片风格符合视觉圣经。
- [ ] 放大、缩小、转场、特效都对应剧情目的，没有连续滥用。
- [ ] 人脸、眼睛、手、关键道具、文字在安全区内。

## 6. 字幕与包装

- [ ] 字幕符合项目的开关和语言设置。项目要求无字幕的，没有任何字幕。
- [ ] 字幕逐字正确，断句符合语义，按实际阅读速度读得完。
- [ ] 花字只强化核心信息，不遮脸和关键物，最后停稳可读。
- [ ] 画面里没有乱码、水印、多余的文字。

## 7. 技术规格

实测值，不是设置值：

- [ ] 画幅
- [ ] 分辨率
- [ ] 帧率
- [ ] 时长，在时长档范围内
- [ ] 文件可以正常打开播放

## 8. 版权与平台

- [ ] 音乐、音效、字体、素材的来源和授权状态都已登记。
- [ ] 符合发布平台的要求（以项目配置为准）。

## 结论

- 需返修的项，写清时间码、问题、归属模块（剪辑、生成、分镜、资产、剧本）。
- 结论写入总控的关卡记录。

## 复盘输出

终检通过后，记录交给学习模块：

- 保留下来的有效决定
- 失败的原因，以及来自素材、剧本、分镜、剪辑还是工具
- 下一次可以迁移的规则
- 是否需要用户确认入库

单次的偏好不自动升级为长期规则。
