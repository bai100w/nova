# 节奏与转场

## 节奏的单位是“变化”，不是固定秒数

按当前表演语言的真实说话速度计算时长。下面只作为初剪检查的起点，台词、动作或停顿没有完成时不为了数字硬剪：

| 节拍 | 常见可读时长 | 主要任务 |
|---|---:|---|
| 钩子 / 异常 | 0.5--2 秒 | 让观众立即看到冲突、情绪或问题 |
| 动作或物件细节 | 0.6--1.8 秒 | 看清触发、手势、道具状态变化 |
| 短反应 | 0.8--2.0 秒 | 给一句话或一个发现落地 |
| 单句对白 | 按完整口播 | 不能切词或压快语速 |
| 情绪停顿 | 1--3 秒 | 让人物做选择，而非无意义发呆 |
| 场景转换 | 0.5--1.5 秒 | 交代新的时间、空间或心理距离 |

检查一段画面时，观察新的信息、表情/视线、手部动作、画面尺度、声音引导或文字重点是否推进。有效停顿也可以维持画面，不能强制每 1--3 秒造变化。若观众没有理由等待，先检查上游剧情和素材，而不是连续使用推近和音效掩盖。重点节点的强弱、铺垫和音画字协同读 [音画节拍](音画节拍设计.md)。

## 转场决策表

| 情况 | 首选 | 原因 | 不该用 |
|---|---|---|---|
| 反转、打断、动作落点、关键信息出现 | 硬切 | 让下一张画面直接回答观众的下一个问题 | 花哨转场、长叠化 |
| 同一动作在不同景别继续 | 动作匹配切 | 保持动作因果 | 不连贯的跳剪 |
| 下一句/声音更有吸引力，想提前拉观众 | J-cut | 下一个声音先进入，再切到来源画面 | 没有视觉依据的过长声音抢跑 |
| 当前一句仍要落地，但画面已该看对方/道具 | L-cut | 当前声音跨到反应或证据画面 | 让旧台词拖到下一场已无法理解 |
| 时间流逝、回忆、情绪软转 | 短叠化 | 让观众感到连续而非冲击 | 用作普通对白的默认转场 |
| 同一人删停顿或重复动作 | 谨慎跳切 | 压缩重复，不改变动作逻辑 | 跳过重要步骤、让脸在竖屏中猛跳 |

J-cut 与 L-cut 优先用于情绪和叙事，不是装饰。先尝试硬切、短 J-cut、短 L-cut 三个版本，再保留最清楚的一版。音频提前/延后应以半拍到一句短语为单位微调，必须回听字幕是否仍能辨认说话人。

## 放大、缩小与关键帧

- 真实视频已有可用近景时，优先切到近景，不用数码放大假装有镜头。
- 漫剧的静态画面，或确有叙事依据的稳定视频，可用缓推、短促到位、先快后慢或推后停住；幅度取决于原构图、目标景别、素材分辨率和情绪。小幅 3--7% 仅是一种试剪起点，较大的局部强调也可能必要。
- 冲击词、抬眼、手指触碰、证据落桌先定义 t0，再写比例/位置/缓动/停留。不要只在整段首尾放两个线性缩放点；快推抓注意、慢推供理解、下一镜复位可以形成不同节拍。源视频已有的推近先计入，不无意叠成双重推镜。
- 放大必须保留眼睛、手和关键道具在竖屏安全区内，不能切掉头顶、下巴、字幕或既定服装细节。
- 一段无实际变化的站桩画面，不能只靠反复缩放变得“有节奏”；回到素材、反应镜或上游补镜解决。

## 不同篇幅的节奏

具体位置以时长档案为准。下面是剪辑时的检查重点：

- **短片（1 分钟内）：** 开场钩子要在最初几秒内成立，剪辑不能再给它加铺垫。全片只有一次主要的强弱变化，大多数时间维持较高的信息密度，但反转或落点之后要留出一小段余韵，不要一落点就结束。
- **中片（3 分钟左右）：** 至少有一次明显的缓急变化。主反转前的一段适当放慢，让观众有预期；集尾钩子之后快速收住。
- **长片（6 分钟左右）：** 按段落安排，每个段落内部有自己的起伏。整集要有一到两处气口，让节奏明显松下来。全程高密度的剪辑会让最高点失去分量。

在时间线上把每个段落的平均镜头长度标出来，和情绪曲线对照：紧张的段落镜头变短或出现长镜头凝视，放松的段落镜头变长。曲线平的地方，先看素材和分镜，再决定剪辑能做什么。

## 反模式

不要把每个切点都配 whoosh、每句台词都推近、每次换场都套模板转场。观众会注意到剪辑工具，而不是人物关系。
