# 对白

## 一句台词的工作

每句台词至少做下面三件事里的两件，只做一件的考虑删掉或合并：

- 推进情节：说完之后局面有变化。
- 揭示人物：只有这个人会这么说。
- 传递信息：观众需要知道的事。

只传递信息的台词最容易写，也最容易让观众走神。

## 潜台词

人很少直接说出自己想要什么，尤其在有冲突的时候。人物嘴上说的和心里要的之间的距离，就是潜台词，也是表演的空间。

把心里话直接说出来的台词，行话叫“太直白”：

- 太直白：“我很生气，因为你从来不把我的事放在心上。”
- 有潜台词：“没事。你忙你的。”（同时把他那份饭倒进了垃圾桶）

写法：

- 先写出人物在这一刻真正想说的话，再问：他为什么不能直说？怕丢面子、怕撕破脸、在试探、在掩饰。然后写他实际会说的话。
- 让动作和台词相反。嘴上说没事，手上在做有事的事。
- 让人物答非所问。回避本身就是回答。

不是每句都要有潜台词。情绪的最高点，人物终于把话挑明，这句直白的台词会很有力量，前提是前面一直在忍。

## 人物的声音

把说话人的名字遮住，应该还能分出是谁说的。区分人物的手段：

- 句子长短：有人说整句，有人只说半句。
- 用词：职业、年龄、地域、受教育程度带来的词汇。
- 习惯：口头禅、爱反问、从不说谢谢。
- 态度：直接还是绕弯，先说结论还是先铺垫。

人物小传里的“说话习惯”一栏要落到台词里。所有人都说一样漂亮的话，是最常见的问题之一。

## 说得出口

台词是给人念的，也是给配音和口型模型用的。

- **短。** 一句一个意思。长句拆成短句，中间留出反应和动作的位置。
- **顺。** 自己念一遍。绕口、拗口、一口气念不完的，改。
- **不产生歧义。** 多音字、生僻字、数字、英文缩写，标明读法。配音模型读错的地方，多半出在这里。
- **留气口。** 该停顿的地方用标点或舞台提示标出来，停顿的长短影响计时。
- **和画面分工。** 画面已经表现的，台词不重复。

一个镜头承载的台词量有限。起点是一个镜头一到两句，更长的台词在分镜阶段会被切成多个镜头或配上反应镜，写的时候就预留能切的位置。

## 旁白和内心独白

- 旁白讲画面讲不了的东西：时间跨度、人物看不到的事、带态度的评价。旁白复述画面，等于浪费时间。
- 内心独白只在外部表现和内心相反时才值得用。心里想的和脸上演的一样，就不需要说。
- 形态档案决定依赖程度。漫剧常以旁白为主干，真人短剧的旁白越少越好。
- 标清类型。旁白、内心独白、画外音在声音处理和口型上各不相同，下游靠标注区分。

## 朗读计时

每一稿都做，方法：

1. 按正常表演的语速估算台词时长。起点值：普通话对白每秒大约 4 个字，旁白略慢，情绪重的戏更慢。有条件就实际念一遍或用配音模型试读，以实测为准。
2. 加上停顿、反应和没有台词的动作时间。动作描述越多，这部分越长。
3. 按节拍汇总，和节拍表上的时长对照。
4. 总时长与时长档案比较。

**汇总用脚本核对。** 把节拍表导出成和预演清单相同格式的 CSV（每个节拍一行，镜号填节拍序号，时长填计时结果，节拍和强度照填），运行：

```
python ../drama-editing/scripts/build_animatic.py 节拍计时.csv --check-only --target <最短>-<最长> --hook-by <秒>
```

它会给出总时长、钩子位置，以及台词是否太密。没有 Python 的环境，在剧本里注明“手算，未经脚本核对”。

超时的处理顺序：先删只做一件事的台词，再合并功能重复的节拍，再回到大纲取舍情节。不通过加快语速来解决，也不交给分镜去删。

计时结果写进节拍表，随剧本一起交付。

## 自查

- 每句台词至少做了两件事。
- 没有人物在向已经知道的人讲解背景。
- 遮住名字能分出说话人。
- 冲突中的关键台词有潜台词，直白的话留给了最高点。
- 念一遍，没有绕口的句子。
- 多音字、数字、英文的读法已标注。
- 每句台词标了说话人和类型。
- 朗读计时在时长档范围内。
