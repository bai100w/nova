# 可制作性审查

定稿前做。目的是在不花钱的阶段，把生成时容易失败的内容找出来，决定怎么处理。

## 判断依据

按下面的顺序叠加：

1. 本文件的通用清单。它是起点，模型在进步，其中一些条目会过时。
2. 形态档案第 10 节“给剧本的可制作性提示”。
3. 项目所选模型适配卡里的“已知弱点”。有适配卡时以它为准。

## 通用清单

| 写法 | 为什么难 | 可以考虑的替代 |
|---|---|---|
| 三人以上同框，并且每个人都要看清脸、有互动 | 人数越多，身份越容易串，站位越难控制 | 拆成单人和双人镜头，用视线和声音交代其他人在场 |
| 拥抱、打斗、搀扶、递接物品等肢体接触 | 接触的部位容易变形、穿模 | 写接触前和接触后，接触的瞬间用局部、遮挡或声音带过 |
| 手部的精细动作：写字、弹琴、系扣子、用筷子 | 手指数量和关节容易出错 | 用手腕以上的镜头、物件的结果（写好的字）、或声音代替 |
| 画面里需要读懂的文字：信件、手机屏幕、招牌 | 生成的文字常常不可读或写错 | 标注为后期排版，剧本里写清文字内容和出现方式 |
| 人群、群戏 | 面孔和动作容易混乱 | 用背影、虚化的远景、声音表现人多 |
| 一个长镜头里连续做多件事 | 单次生成时长有限，动作越多越容易漂移 | 一个镜头一个主要动作，在剧本里就写出可切的节点 |
| 镜子、玻璃倒影、屏幕里的人 | 两个影像很难保持一致 | 改变角度避开，或只留一个影像 |
| 换装、变身、受伤等外观在画面内变化的过程 | 变化过程不稳定 | 切走再切回，只呈现变化的前后 |
| 吃东西、喝水 | 口部和物体的交互容易变形 | 写端起和放下，中间切到别处 |
| 动物和幼儿的具体表演 | 动作难以指定 | 降低对具体动作的要求，或减少出镜 |
| 精确的道具操作：开锁、打字、组装 | 道具状态和手难以同步 | 拍结果和反应，过程用声音 |
| 同一角色出现多个年龄段 | 每个年龄段都要单独做资产并保持像同一个人 | 减少年龄段，或用道具、旁白交代时间 |
| 大段台词配一个不切的正面镜头 | 口型长时间同步的要求高 | 预留反应镜、画外音、侧背面的位置 |

另有一类不属于技术难度，但同样要在剧本阶段处理：真实存在的名人、品牌、商标、受版权保护的角色和作品。这些不写进剧本，改用虚构的替代。

## 怎么处理

每个命中的地方三选一，并记下选择：

- **改写。** 换一种更好做、戏剧效果相同或更好的写法。很多时候限制会带来更好的写法，不展示打斗过程、只拍门外听到的声音，常常比直接拍更有力量。
- **拆解。** 保留内容，标注给分镜，拆成多个简单镜头。
- **保留并标高风险。** 这场戏的核心就是这个画面，不能换。那就保留，并提醒总控为它预留更多的重试预算，提醒分镜准备备选方案。

不要一刀切。审查的目的是把预算花在值得的地方，不是把所有难拍的戏都删掉。故事的情绪最高点哪怕很难做，也应该保留。

## 资产预算

顺便清点这一稿需要的东西，因为每一项都是制作成本：

- 有名有姓、需要保持一致的人物有几个，其中几个是新增的。
- 场景有几个，其中几个是新增的。
- 需要反复出现或有状态变化的道具有几件。
- 需要固定声线的角色有几个。

与时长档案的建议规模比较。超出时列出可以合并的人物和场景，由用户决定。
