# 拆解与台词表

定稿之后，把剧本拆成下游可以逐条核对的表。它的作用是保证剧本里的每一个字都有去处：要么变成画面，要么变成声音，要么明确标为不出现。成片里漏台词、错顺序、缺道具，多数能追溯到这一步没做或没做全。

模板见 [拆解与台词表模板](../templates/拆解与台词表模板.md)。

## 逐段拆解

1. **建立原文映射。** 把源稿按场次切成段落：动作段、对白、旁白、内心独白、画外音、环境喊话、换场。顺序和文字与源稿完全一致。
2. **给每段一个稳定编号。** 格式是集、场、段，例如 EP01-S01-P001。编号一经使用不再改动。修订时新增的段落用新编号，并记下它替代或插在哪一段之后。
3. **记录源稿版本。** 拆解表对应哪一版剧本，写在表头。
4. **逐段标注它需要什么：** 出场人物及其状态（服装、伤情、情绪），场景及时间，道具及其状态，声音（谁说话、环境声、特殊声音），出入口和位置变化。
5. **标出新增项。** 本集第一次出现的人物、场景、道具，说明来源。

**核对方式：** 逐字比对。段落数量相等不能代替逐字比对。已有一份确认过的映射时可以直接沿用。

拆解表交给资产模块，由它汇总成五类资产总表。剧本不直接交给分镜。

## 台词表

从拆解表里抽出所有要发声的段落，每行包含：

| 栏 | 内容 |
|---|---|
| 段落编号 | 与拆解表一致 |
| 说话人 | 角色编号和名字 |
| 类型 | 对白、旁白、内心独白、画外音、环境喊话 |
| 原文 | 与源稿逐字一致 |
| 表演文本 | 实际要念的文本。不做本地化时与原文相同 |
| 语气与停顿 | 表演提示、读法标注 |
| 时长 | 朗读计时的结果 |
| 确认状态 | 草案、待确认、已确认 |

**规则：**

- 冒号后面、引号里面的字，不一定是口播。屏幕上的字、道具上的字、舞台提示，单独列出，不进台词表。
- 长句为了分镜需要拆成几段时，各段拼回去必须等于确认的台词。
- 台词表在分镜计时之前锁定。锁定后不能有待翻译或空着的行。
- 锁定之后的修改回到剧本模块出新版本，不在下游改。

## 本地化

只在项目需要时做。单语项目不额外加第二种语言。

- 原文保留不动，译文写在表演文本一栏，逐句对应。
- 自然的口语不等于删信息或改动机。译文要保住这句台词原本做的事：推进了什么、揭示了什么。
- 幽默、称谓、口音、文化背景，按目标市场处理，并在备注里说明处理方式。
- 译文的时长重新计时。不同语言的长度差别很大，超时要回到剧本层面解决。
- 译文需要用户或指定的审校人确认后才算已确认。

## 变更

剧本改了，拆解表和台词表跟着出新版本，并标出改动涉及的段落编号。受影响的资产和下游由总控标为需复核。不通过改台词来掩盖缺资产的问题。
