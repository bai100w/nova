# 角色设计

角色是观众注意力停留最久的地方。一个好的角色设计，在手机屏幕上缩到很小、只出现一秒，也能被认出来，并且看一眼就大致知道这是什么样的人。

先写 [角色设定卡](../templates/角色设定卡模板.md)，再生成。设定卡的依据是人物小传、视觉圣经和形态档案。

## 辨识度

按观众认人的顺序设计：

1. **剪影。** 把人物涂成全黑，还能分出是谁吗？靠的是体型、发型轮廓、标志性的服装或配饰外形。主要人物之间的剪影要有明显区别：一高一矮、一个长发一个短发、一个宽松一个利落。
2. **主色。** 每个主要人物有一个归属色，来自视觉圣经的色彩归属。主角和对手的主色要拉开。同场的人物撞色，观众在快速切镜时会混淆。
3. **发型和脸型。** 写实形态里，发型是区分人物最有效的手段之一，比五官更容易保持一致。
4. **细节。** 一件始终戴着的东西：一副眼镜、一枚戒指、一道疤。它是辨识的保险，也常常能承载故事。

检查方法：把所有主要人物的全身图缩小并排放在一起，看能不能在一秒内分清。

## 外形讲故事

外形的每个选择都应该能对回人物小传：

- **服装说明处境。** 职业、阶层、经济状况、此刻在乎什么。衣服是新的还是旧的，合身还是不合身，整齐还是凌乱，都在说话。
- **服装跟着人物弧变。** 人物变了，外在也可以变。一个从被动到主动的人物，造型可以从柔软、遮掩变得利落、明确。在设定卡里写清楚有几个造型、各自适用哪些场次、为什么变。
- **和原型拉开一点距离。** 题材有常见的人物外形，例如总裁一身黑西装。可以用，但加一处属于这个人的细节，并让它和人物小传里那个“与原型相反的细节”呼应。
- **符合世界观。** 年代、地域、阶层、规则下的人会穿什么。架空世界也要有内部的一致逻辑。

不需要每个配角都精心设计。功能性的配角和路人，保证不抢主要人物的辨识度即可，主色往往选得更灰、更弱。

## 按形态准备的资产

具体规格以形态档案第 2 节为准。通用的起点：

| 形态 | 主要角色通常需要 |
|---|---|
| 真人短剧 | 正面、四分之三侧、侧面的脸部图；全身正、侧、背；每个造型的全身图；必要的表情 |
| 3DCG 动画 | 转面图（正、侧、背、四分之三）；材质和渲染风格说明；比例图；表情 |
| 2D 动画 | 设定稿三视图；表情集；色彩指定（各部位的颜色，包括阴影色）；比例图 |
| 漫剧 | 立绘；表情差分；必要的动作差分 |

表情和动作只做剧本高频用到的和关键戏需要的，不为凑满九宫格增加用不到的状态。

## 比例

- 每个主要人物登记身高和头身比，数值来自项目设定。
- 经常同框的两个人，做一张并排的比例图。这是比例的权威参考。
- 人物和常用道具、家具的比例也要对得上：桌子到人的哪里，门比人高多少。

## 变体

**年龄变体。** 同一人物的不同年龄段共享一个身份基准：骨相、五官的位置关系、标志性特征保持一致，只改变年龄带来的变化。每个年龄段单独登记，写明适用场次。

**造型变体。** 换装、受伤、湿身、妆容变化，每一种都是一个登记项，写明适用场次和从哪一场开始、哪一场结束。

**状态继承。** 变体在剧情里出现后，后续场次默认继承，直到剧情交代它变回去。这部分记进尺寸与连续性槽位。

## 生成要点

- 先做身份图，确认后再以它为基础做全身、服装、表情。不要每张图都从文字重新生成。
- 身份图用简单的背景和均匀的光，让脸的结构清楚。好看的光影留给光影标定。
- 三视图和转面图的各个角度，比例和细节要一致：正面有的口袋，侧面也要有。
- 生成的结果不像设定时，先判断是请求没写清，还是模型的弱点。后者记进适配卡。
