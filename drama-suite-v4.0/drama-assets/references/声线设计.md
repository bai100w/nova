# 声线设计

声音占观众感受的一半，但最容易被当成最后一步随便配上。声线一旦定下，全剧都要用它，中途换声线比换脸还让观众出戏。所以声线要和角色同时设计、同时验收。

项目对配音、旁白、背景音乐的规定以项目配置为准。

## 选声线

**从人物出发。** 读人物小传和表演基调，先回答：这个人说话是什么样的？再找声音。

| 维度 | 要决定的 |
|---|---|
| 音高 | 偏高、中、偏低 |
| 音色 | 清亮、温润、沙哑、气声多、有颗粒感 |
| 年龄感 | 与人物的年龄阶段一致 |
| 语速 | 快、中、慢，和人物的性格和表演节奏一致 |
| 质感 | 圆润还是有棱角，松弛还是紧绷 |
| 口音与方言 | 剧情需要时才加，并确认配音模型能稳定做到 |

**角色之间要分得开。** 闭上眼睛听两段对话，能分出是谁在说。经常同场的人物，音高或音色至少一项明显不同。

**和外形相符或有意相反。** 多数时候声音和外形一致。有意的反差（外形柔弱、声音冷硬）可以成为人物的特点，但要在设定卡里写明这是设计。

**旁白。** 旁白是谁的声音：某个角色，还是一个全知的叙述者。贴近还是有距离。旁白的声线和角色的声线也要分得开。

## 试音

不能只凭文字描述确定声线，必须实际试听。

**试音台词要覆盖情绪的两端。** 准备三到五句，来自剧本或按人物写：

- 一句平常的话，听基本的音色和语速。
- 一句情绪低的话：疲惫、压抑、悲伤。
- 一句情绪高的话：愤怒、激动、喊叫。
- 一句有潜台词的话，听能不能演出言外之意。
- 剧本里最重要的一句台词。

很多声线在平常的话里很好听，到了情绪高点就失真或变得滑稽。试音要暴露这一点。

**记录：** 试音文本、所用模型和声线设置、样本文件、精确时长、听后的判断。

## 登记

确定的声线登记为声音资产：

- 角色编号、声线名称或参数、所用模型和适配卡
- 确认的样本文件、精确时长、格式
- 适用的语气范围，以及已知做不好的语气
- 平台上的编号和对应的本地样本（平台托管时）
- 状态和确认来源

文字写的音色规格不等于样本，必须有可以听的文件。固定的声线不能用临时找的相似声线替代。

## 其他声音资产

需要提前确定、在多处重复使用的声音，也登记为资产：

- 导演模块声音概念里的标志性声音。
- 某个场景特有、贯穿多场的环境声。
- 剧情需要的特定声音，例如一段反复出现的手机铃声。

普通的音效和环境声在后期处理，不在这里登记。
