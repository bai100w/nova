# 资产验收

验收的前提是实际看过图、听过声音。没有看过的标“未核验”，不能记为通过。

## 两类资产，分开验收

| 类型 | 目的 | 怎么做 | 验收看什么 |
|---|---|---|---|
| 结构资产 | 保证一致性：脸、比例、服装、布局、道具 | 简单背景，均匀光，足够的景深 | 结构是否清楚、准确、各角度一致 |
| 光影标定 | 验证资产在本片的光线和画风下的样子 | 按画面预设表的光线，用代表性的局部构图 | 在本片光线下是否好看、是否仍然认得出 |

两者不能互相替代：

- 结构资产不够好看是正常的，它不是成片画面。不能因为它平淡就去加光影，加了光影反而遮掉结构。
- 光影标定再漂亮，也不能当作结构资产使用。它的光影会干扰后续生成对脸和服装的判断。
- 光影标定在资产阶段做，但它不是分镜。不展开全片镜表，不锁定镜头时长和生成包。

## 按形态的验收重点

以形态档案第 4、8 节为准。通用的起点：

**真人短剧**

- 脸：五官比例正常，左右对称程度自然，各角度是同一个人。
- 皮肤：有真实的质感，不过度磨皮，不像塑料。
- 眼睛：有神，视线方向正确，没有瞳孔异常。
- 手：手指数量和关节正确。
- 头发：发丝自然，发际线和发型在各角度一致。
- 年龄：看起来是设定的年龄阶段。

**3DCG 动画**

- 模型的比例和结构在各角度一致。
- 材质：皮肤、布料、金属等材质的表现符合视觉圣经的渲染风格，没有闪烁或错误的反光。
- 渲染风格在所有资产之间统一。

**2D 动画**

- 线条：粗细和风格符合视觉圣经，各视图一致。
- 上色：颜色和色彩指定一致，阴影的分层方式统一。
- 造型：比例在各视图和表情之间不走样。

**漫剧**

- 画风：所有立绘和差分的画风统一。
- 造型：表情差分之间，除了表情以外的部分完全一致。
- 立绘的姿态是否适合后续的画面运动和构图。

## 通用检查

| 检查项 | 看什么 |
|---|---|
| 与设定卡一致 | 外形、服装、配色、标志性细节都在 |
| 辨识度 | 缩小后与其他主要人物并排，一秒内能分清 |
| 与视觉圣经一致 | 色彩、质感、画风符合规定，在风格对标的认可范围之内 |
| 比例 | 与比例图、其他人物、家具道具的比例对得上 |
| 左右和朝向 | 惯用手、持物侧、饰品位置、服装的不对称细节，各视图一致 |
| 场景结构 | 门窗家具的位置与布局图一致，反打的两个方向对得上 |
| 实景光源 | 场景里的光源在设定的位置 |
| 道具 | 尺寸、正反、状态与登记一致 |
| 声线 | 试音覆盖了情绪两端，与人物相符，与其他角色分得开 |
| 技术规格 | 实际像素或时长、格式 |

## 记录

每项资产的验收写进总表的“实际验收证据”一栏：谁在什么时间看了哪个文件，结论是什么。不通过的写原因和下一步。

用户确认的，写明确认的范围。例如：“确认了脸和发型，服装待改。”确认一部分不等于全部通过。

## 不通过时

先判断原因：

| 原因 | 处理 |
|---|---|
| 设定卡没写清 | 改设定卡，重新生成 |
| 请求丢了约束 | 改请求，重新生成 |
| 模型的稳定弱项 | 记进适配卡；改设计绕开，或换一种生成方式 |
| 设计本身和视觉圣经冲突 | 退回导演模块 |

同一项资产两轮仍不过，停下来和用户商量。不能用风格测试或生成试片来补资产的缺口。
