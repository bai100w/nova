# 场景与道具设计

## 场景是戏的一部分

场景不是背景板。一个房间在告诉观众住在这里的人是谁、过着什么样的生活、此刻处境如何。场景设计也决定了分镜能怎么拍：门在哪里，人物从哪里进来，光从哪里照进来，摄影机能放在哪里。

先写 [场景设定卡](../templates/场景设定卡模板.md)，再生成。依据是剧本的场景大纲、视觉圣经和画面预设表。

### 空间讲故事

- **住在这里的人。** 物品的数量、新旧、整齐程度、个人痕迹。空荡的豪宅和堆满东西的出租屋，在人物开口之前就讲了一半的故事。
- **年代、地域、阶层。** 家具、电器、装修材料、墙上的东西。架空世界也要有内部一致的逻辑。
- **与人物的关系。** 人物在这个空间里自在还是局促，是主人还是外人。可以通过空间的尺度、人物与家具的比例来表达。
- **随剧情的变化。** 场景会不会在故事中改变：被破坏、被收拾、被布置。每一个状态单独登记。

### 布局与动线

分镜要靠布局图来保证连续性，所以布局要明确：

- 平面上各个主要物件的位置：门、窗、桌、床、柜。
- 出入口有几个，各通向哪里。
- 人物在这场戏里的活动路线和主要的停留位置。
- 摄影机主要会从哪几个方向拍，这几个方向上各自能看到什么。

一个场景至少登记一张无人的布局图。经常反打的场景，两个方向的背景都要做，并且对得上。

### 前中后景

为分镜准备纵深：这个空间里有什么可以放在前景（门框、植物、栏杆、桌上的杂物），中景是人物活动的区域，后景能看到什么（窗外、走廊、另一个房间）。有层次的空间才能拍出有层次的画面。竖屏项目尤其需要纵向的层次。

### 实景光源

视觉圣经要求光有来源。场景设计要把这些来源放进空间：窗的位置和朝向、灯的种类和位置、屏幕、火、霓虹。写清楚：

- 每个光源在哪里，什么颜色，亮度大致如何。
- 不同时间段，哪些光源亮着。
- 主光来自哪个方向，这决定了分镜在反打时如何保持光位一致。

光源的位置一经确定，就是这个场景的固定事实。分镜和生成都以它为准。

### 色彩与人物分离

场景的颜色要给人物留出位置。如果主角的归属色是暖红，她常待的房间就不要也是暖红，否则人物会融进背景里。参考视觉圣经的色彩脚本，场景色和人物色之间保持对比。

## 道具

### 哪些道具要单独设计

- 剧情关键道具：推动情节、承载线索、反复出现的。
- 人物会拿起、使用、交给别人的。
- 有状态变化的：会被打碎、打开、写上字、弄脏的。
- 视觉母题相关的。

其余的背景物件随场景一起处理，不单独登记。

### 主道具要写清的

| 项 | 内容 |
|---|---|
| 外观 | 形状、材质、颜色、新旧程度、标志性细节 |
| 实物尺寸 | 以厘米计，或相对于人手、人体的比例 |
| 正反和朝向 | 有文字、有图案的面在哪一边 |
| 持握方式 | 用哪只手、怎么拿、手放在哪里 |
| 状态 | 初始状态，以及在哪一场变成什么状态 |
| 意义 | 它在故事里代表什么，是否和人物或母题相关 |

### 道具上的文字

信件、证件、屏幕、招牌上需要读懂的文字，生成时往往不可读或写错。处理方式和剧本的可制作性审查一致：道具图上留出空白或做成不可读的纹理，准确的文字由后期排版加上。在道具登记里写明哪些文字归后期。

### 道具状态的连续性

道具在每一场开始和结束时的状态，记进尺寸与连续性槽位：在谁手里、在什么位置、是什么状态。分镜按这个继承，不能凭空到手或凭空消失。

## 生成要点

- 场景布局图用足够的景深和均匀的光，让结构清楚，可以核对门窗和家具的位置。它不需要好看。
- 好看的光影单独做光影标定，见 [资产验收](资产验收.md)。
- 道具图用简单背景，正面和必要的侧面、背面，并附一张和人手或人物同框的比例参考。
