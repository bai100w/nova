# 账号视频学习

适用于用户给多个账号，并要求学习全部内容、画面、分镜、节奏、声音并优化已有 skill。用户说“全部”时，全量目录就是范围；初批处理或代表片只决定顺序，不能自动改为只学最新、高赞或固定30/50/80条。用户指定平台与学习目标后直接执行，不重新进行无关模式问卷。

## 先固定范围

对每个账号记录用户原始链接、页面核验名、采集日期、主页作品数、已收录的唯一视频ID和末页状态。置顶不代表最新，同一系列不等于同一条；合集页、推荐区、评论中的其他视频不能混入作者目录。主页数字与收录数有差异时先排查懒加载、重复、图文和不可访问项。

逐条维护状态，不以一份总结代替覆盖清单：

`视频ID / 账号 / 标题 / 主页链接 / 当前作品链接 / 时长 / 封面 / 画面 / 镜序 / 节奏 / 声音与BGM / 证据位置 / 规则ID / 尚未核验项`。

状态可取未检查、局部检查、已完整检查、无法访问。元数据已读取不代表画面已看，播放器一直播放不代表已完整观看，点击取消静音不代表已听到声音。完整学习比例按各维度实际检查计算。

## 画面与分镜

- 封面只分析首屏选材和包装；封面可能经过特殊设计，不能替代全片风格。
- 封面裁切比例与正片画幅分别记录，先查正片实际解码宽高。账号主页的竖向卡片不证明作品为竖屏；横屏镜头关系要按目标画幅重新设计后才迁移，不能直接中心裁切成竖屏。
- 单帧记录人物占比、机位观感、背景层次、明暗与冷暖、肤质/材质、主体与道具关系、字幕和文字层。焦段、光圈、灯具、原生分辨率无实测时标为视觉推断。
- 连续片段才记录镜序、视线、空间、动作接点、运镜起终、反应滞后和信息释放；稀疏截图只能说明采到的画面，不能计成完整切点表。
- 同一账号按题材、系列、场景和日期比较，保留有效差异。五个账号各有结论后再比较共性；高赞数据只能表明相关，不证明某种打光或BGM造成高赞。

## 节奏与声音

把关键段写成“铺垫—触发—强调—反应/余韵”，记录来源时间区间和对应操作。镜头长度、停顿、放大曲线、字幕变化与音乐节拍分别测量，再判断它们何处协同。源视频已有运镜和后期数码放大无法区分时，只描述最终画面运动，不擅自归因。

BGM最少记录：实际可听区间、进入/退出、乐句变化、疏密/速度观感、音色、对白遮蔽、关键音效瞬态、留白。平台“原声/原创音乐”名称、听感描述、曲目识别结果分别保留；平台原声可能包含对白与多首配乐，不自动等于底层BGM名称。没听到就不填曲名、BPM、duck或乐器。

不能下载时仍可在正常播放界面分析可观察范围。先记录媒体读取失败与当前页面状态，再选择可执行方式；不反复发起相同下载、不把blob地址当成本地媒体。遇登录或验证码按实际情况处理，不能把访问失败写成学习成果。

## 入库与分发

用户已经明确要求沉淀和优化，即授权本轮按 [沉淀与复盘](沉淀与复盘.md) 的层级写入：要求写进项目的写进项目规律，要求修改 skill 的才改套组。无需再逐条索要同一许可。每批只采用证据支持的规则，保留历史版本及变更原因：

| 规则内容 | 接收模块 | 必须带的来源 |
|---|---|---|
| 关系、钩子、结构与集间承接 | drama-script | 实际剧情段落；只有标题时仅列候选假设 |
| 色彩、光线、质感、整体视听风格 | drama-direction | 帧或连续片段，时间与推断边界 |
| 人物造型、场景美术 | drama-assets | 帧证据；参考人物的脸不进入项目身份资产 |
| 镜头、构图、调度、表演 | drama-storyboard | 连续片段的时间段 |
| 生成上的做法（某类镜头怎么写请求效果好） | drama-production | 对应的请求和结果 |
| 切点、停顿、音画节拍、BGM、字幕、花字 | drama-editing | 镜序或声音区间和具体操作 |
| 封面与物料 | drama-materials | 封面证据与对应视频，不混用为正片参数 |

每条规律写：触发条件 -> 操作 -> 预期作用 -> 不适用场景 -> 来源账号/作品/时段 -> 已检查与未检查维度。项目具体脸、服装、剧情、曲目、字幕语言、品牌和视觉值留在项目资料中。

最终报告展示账号目录数、每个维度的实际覆盖、不可访问项、采纳规则及对应skill改动。只做了目录或局部样本时继续保留未完成状态，不能将“全量列出”改写为“全量学完”。
