# 参考拆解方法

## 先确定看什么

一个参考可以学很多方面。先问用户想学什么，或者根据参考的类型判断：

| 方面 | 看什么 |
|---|---|
| 剧本 | 钩子、结构、节拍、反转的铺垫、人物的建立、对白、集尾 |
| 视觉 | 色彩、光线、构图、景别、镜头运动、质感 |
| 表演 | 表演的幅度、节奏、微表情、反应 |
| 剪辑 | 镜头长度、切点、转场、节奏的变化 |
| 声音 | 音乐的风格和进出、音效、静默、对白的处理 |
| 包装 | 字幕、花字、片头片尾、封面、标题 |

不确定时，先整体看一遍，记下最突出的两三个方面，再深入。

## 怎么看

1. **先当观众看一遍。** 不暂停，只记下自己的感受：哪里被抓住了，哪里走神了，哪里印象最深。这些感受是要解释的对象。
2. **再逐段拆。** 回到印象最深的地方，逐镜或逐句看：它是怎么做到的？
3. **核对证据的类型。** 每一条观察标明来自哪里：连续播放、逐帧、截图、只有封面、只有标题。

**证据的边界：**

- 单张截图能支持对色彩、光线、构图的观察。
- 连续的片段才能支持对镜头顺序、运动、节奏、表演的分析。
- 听过声音才能分析音乐和音效。
- 封面的比例和正片的画幅分开记录。竖向的封面不代表正片是竖屏。

## 提炼

每一条发现写成四部分：

1. **效果：** 观众感到了什么。
2. **手段：** 由哪些具体的画面、动作、声音、文字实现。
3. **条件：** 什么时候有效，什么时候不适用。
4. **证据：** 来源的作品、时间段、证据类型。

**例：**

- 效果：反转的那一刻让人后背发凉。
- 手段：反转之前三秒，音乐完全停下，只剩极轻的环境声；反转的画面出现时没有任何音效，人物也没有立刻反应，停了大约一秒才转头。
- 条件：适用于悬疑和惊悚的反转。前面需要有足够长的音乐铺垫，静默才有对比。不适用于需要爽感释放的反转。
- 证据：参考 A，02:13 至 02:20，连续播放并听了声音。

不合格的提炼：“声音设计很高级，营造了紧张氛围。”说不出手段和条件，下游无法执行。

## 推断的写法

无法直接观察的东西，可以推断，但要标明：

- “视觉推断：背景的压缩感和虚化程度接近长焦拍摄。”不能写成“使用 85mm 镜头”。
- “推断：这一段可能是后期的数码放大，而不是镜头内的推进。”无法区分时，只描述最终的画面运动，不归因。
- 平台显示的“原声”名称不等于背景音乐的曲名。

## 参考卡

用 [参考卡模板](../templates/参考卡模板.md)，存进项目资料库的 `references/`，编号 `REF-日期-序号`。

参考卡区分：参考本身的事实，你的分析和推断，给当前项目的建议。建议的状态是“候选”，直到用户采用。

## 版权和边界

- 学习手法，不复制内容：不复制角色、台词、具体的构图、曲目、标志性的画面。
- 参考里的人物的脸，不进入项目的身份资产。
- 参考用了某首曲子，不等于当前项目可以用。
- 高赞只说明相关，不证明是某个手法造成的。
