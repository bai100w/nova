# patterns 文件结构

项目资料库的 `patterns/` 下有四个文件：`script.md`、`assets.md`、`visual.md`、`materials.md`。新项目建资料库时，按下面的结构各建一个，内容为空即可。

这些文件只放本项目的规律。人物、故事、具体数值可以出现，因为它们只属于这个项目。
