# 剧集skill套组 V4.0

一套指导 AI 完成剧集制作全流程的 skill，覆盖真人短剧、3DCG 动画、2D 动画、漫剧四种形态，以及 1 分钟内、3 分钟左右、6 分钟左右三个时长档。不绑定具体的生成模型和工具。

## 版本

当前版本：**V4.0**（2026-11-13）

V4.0 是对旧套组的整体重写。旧套组各模块的版本号各自独立，最高到 v3.2（剪辑模块）；从 V4.0 开始，所有模块统一使用一个版本号，以后的改动按 V4.1、V4.2 递增，大的重构升为 V5.0。

| 模块 | 内容 |
|---|---|
| drama-control | 总控：立项、流程、三道关卡、资料库、模型适配、质量评审 |
| drama-script | 剧本：开发阶梯、结构、场景与人物、对白、可制作性审查、拆解与台词表 |
| drama-direction | 导演与视觉开发：导演阐述、视觉圣经、表演与声音概念、风格测试 |
| drama-assets | 资产：拆解与登记、角色设计、场景与道具设计、声线设计、验收 |
| drama-storyboard | 分镜：镜头语法、场面构建与连贯、表演指导、两版画面合同、纸面预演、分包 |
| drama-production | 生成与审片：请求组装与提交、自动与手动双模式、审片、诊断与返修 |
| drama-editing | 剪辑与后期：预演片生成、剪辑、音画节拍、声音、调色、字幕包装、终检 |
| drama-materials | 宣发物料：封面与海报、标题与文案 |
| drama-learning | 参考学习与复盘：参考拆解、账号学习、沉淀与复盘 |
| 档案 | 4 个形态、3 个时长、10 个题材，以及三份模板 |

旧套组的 drama-autoflow 已并入 drama-control。

**验证情况：** 已用一个 1 分钟真人甜宠短片试跑到预演关卡，并按发现的问题改进。生成、后期、宣发环节还没有接入模型实际跑过，建议接入后再试跑一次，通过后整体替换旧套组。档案里的数值都是起点值，需要用实际项目校准。

## 安装

整套放进同一个 skills 目录，保持目录结构不变。模块之间用相对路径互相引用，拆开单独安装会找不到引用的文件。

- **Codex：** 放进 Codex 的 skills 目录。`agents/openai.yaml` 是 Codex 用的界面信息，其他工具用不到。
- **Cursor：** 放进项目的 `.cursor/skills/`，或沿用已有的 Codex skills 目录。
- **WorkBuddy：** 按它的技能导入方式整套导入，保持目录结构。导入时如果提示文件头格式有问题，检查 SKILL.md 开头的 name 和 description 两行。

各工具的目录位置和导入方式可能随版本变化，以工具当前的说明为准。

`examples/` 是旧项目的案例，不是 skill，不需要单独安装，放在一起即可。

## 怎么开始

对助手说要开一个新剧集项目，或者在已有项目目录里说继续做。助手会先用 drama-control 找项目资料库，没有就带你做立项定档。

## 结构检查

```
python drama-control/scripts/audit_project.py --skills <本目录>
python drama-control/scripts/audit_project.py --root <项目根目录>
```

## 设计要点

- 每个模块都包含三样东西：方法、评分标准、关卡。
- 具体数值只放在项目资料库里。套组里只有方法和模板。
- 差异通过三类档案表达：形态、时长、题材。
- 模型通过适配卡接入，支持自动调用和手动操作两种方式。
