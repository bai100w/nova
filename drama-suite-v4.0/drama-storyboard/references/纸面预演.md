# 纸面预演

纸面预演只花 token，不生成任何画面。预演关卡的放行条件里，大部分（时长、钩子位置、台词完整、节奏是否平、覆盖、轴线、看不看得懂、预算）都能在纸面上检查。所有档位都要做。

它由三部分组成，前两部分可以由同一个会话完成，第三部分必须由独立会话完成。

## 1. 预演清单与时间线

从分镜表导出一份预演清单（CSV，UTF-8），每镜一行：

| 列 | 内容 |
|---|---|
| 镜号 | 必填 |
| 时长 | 必填，秒 |
| 场 | |
| 景别 | |
| 画面 | 一两句话，这一镜观众看到什么 |
| 台词 | 确认台词，原文 |
| 节拍 | 对应节拍表，例如开场钩子、升级、反转、气口 |
| 强度 | 1 到 5，按这一镜单独判断。参考情绪曲线，但不照抄节拍的强度，同一节拍里的镜头可以有起伏 |
| 图片 | 可选，关键帧的路径 |
| 音频 | 可选，临时配音的路径 |

然后运行剪辑模块的脚本：

```
python ../drama-editing/scripts/build_animatic.py 预演清单.csv --check-only --target <最短>-<最长> --hook-by <秒>
```

目标时长和钩子时间取自时长档案。脚本输出一份纸面预演摘要：逐镜的起止时间、总时长、钩子和最高点的位置，以及这些需要检查的地方：连续三镜以上的同一景别，跨越两个以上节拍仍不变的强度，拖得太长的低强度段，过长的单镜，台词可能装不下的镜头。

没有 Python 的环境，按同样的项目手算一遍，写成同样的表。

## 2. 结构检查

对照摘要，逐场检查脚本算不出来的东西：

- 每场有没有建立、关键动作、反应、细节。缺的写出来。
- 轴线和视线有没有错误。
- 每一镜的起始状态是不是继承了上一镜的结束状态。
- 最高点之前有没有足够的积累，之后有没有余韵。
- 中片和长片有没有气口。
- 高风险镜头是否都标了，是否有备选。
- 镜头数乘以重试上限，预算是否在授权范围内。

## 3. 盲读测试

这是纸面预演里最有价值的一步，也是唯一需要独立会话的一步。

**做法：** 另开一个会话或子代理，只给它预演清单的“镜号、画面、台词”三列，不给剧本、不给大纲、不给创作过程。请它：

1. 用几句话复述这个故事。
2. 逐场说出：在哪里，谁在，发生了什么变化。
3. 指出看不懂、有疑问、或者理解和预期可能不同的地方。
4. 说出它在哪一镜最想知道接下来发生什么，在哪一镜开始走神。

**判断：** 把它的复述和剧本对照。复述错的地方、漏掉的地方、产生疑问的地方，就是成片里观众会看不懂的地方。走神的地方，就是节奏有问题的地方。

**为什么必须是独立会话：** 写分镜的会话知道故事，读自己写的分镜一定读得懂，测不出任何问题。

是否允许开独立会话，在立项时已经问过，记在项目索引的授权范围里。允许的直接开，不再询问。

不允许或环境开不了时，把预演清单的“镜号、画面、台词”三列整理成一页，在预演确认点交给用户，请用户找一个没看过剧本的人读，或者用户自己读，然后把复述发回来。用户也不方便的，在关卡记录里注明“未做盲读”，第 3 条放行条件记为未核验。

## 4. 预演摘要

把上面三部分合成一页，交总控过预演关卡，也是交给用户看的东西：

- 时间线概况：总时长，钩子和最高点的位置，各节拍的时间分布
- 脚本发现的问题
- 结构检查发现的问题
- 盲读的复述和它指出的问题
- 每个问题的修改建议和归属模块
- 已经改了哪些，还剩哪些

用户看这一页就能判断，不需要看完整的分镜表。

## 纸面预演检查不了的

画面的实际观感、表演好不好、颜色和光线的效果。这些靠风格测试、关键镜头的静帧，以及生成后的审片。真实的时间感（纸上的 3 秒和看到的 3 秒）可以用文字卡预演片补，见剪辑模块的 [动态预演组装](../../drama-editing/references/动态预演组装.md)。
