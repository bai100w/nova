# 镜头语法

镜头的每个选择都在影响观众的感受。这里列出常用的选择及其效果，供逐镜设计时查用。它们是倾向，不是定律：同一个选择在不同上下文里效果会变。最终以导演阐述和视觉圣经为准。

2D 动画和漫剧没有真实的摄影机，但景别、角度、构图、视点的效果同样成立。焦段和景深的部分，换成画面设计版合同里的透视和虚化方式来表达。

## 景别

景别决定观众离人物有多近，也就决定了观众能看到什么、感受到什么。

| 景别 | 能看到 | 常用来 |
|---|---|---|
| 大远景 | 环境为主，人物很小 | 建立世界的尺度；表现人物的孤独或渺小 |
| 远景 | 人物全身和周围环境 | 交代空间、人物的位置关系、大的动作 |
| 全景 | 人物全身，环境退后 | 肢体动作、走位、人与人的距离 |
| 中景 | 腰部以上 | 对话的基础景别，兼顾表情和手势 |
| 近景 | 胸部以上 | 情绪开始重要的时候；对话中的关键句 |
| 特写 | 脸 | 情绪的高点；观众必须看清的反应 |
| 大特写 | 眼睛、嘴、手、物件的局部 | 最强的强调；关键的细节或线索 |

**用法：**

- **越近，情绪越强，也越用越弱。** 特写是最贵的镜头，留给最重要的时刻。全场都用特写，最重要的那一刻就没有更近的可以用了。
- **景别的变化本身就是节奏。** 从中景切到特写，是一次强调；连续几个同样的景别，观众会感到平。
- **近景和特写要给反应的人，不只是说话的人。** 很多时候，听的人的脸才是这场戏的内容。
- **竖屏手机上，中近景到近景是主力。** 远景里的人物太小，要慎用并且给足时间让观众看清。

## 角度与高度

| 选择 | 效果 |
|---|---|
| 平视（摄影机在眼睛高度） | 平等、客观，观众站在人物身边 |
| 俯拍 | 人物显得弱小、被审视、处于下风 |
| 仰拍 | 人物显得强大、有威胁、处于上风 |
| 正上方俯视 | 疏离，像在观察棋盘；适合表现被困住 |
| 倾斜（荷兰角） | 失衡、不安、精神状态出问题。很容易用滥 |
| 主观视点 | 观众通过人物的眼睛看。增强代入，也用来制造悬念 |
| 过肩 | 对话中保持两人的关系，前景的肩膀提醒观众另一个人在场 |

**用法：**

- 权力关系变化时，角度跟着变。一场戏开头 A 俯视 B，结尾 B 俯视 A，观众不用解释就懂了。
- 两个人对话，机位高度一般与各自的眼睛高度对应。身高差大时，正反打一个微俯一个微仰。
- 倾斜构图和极端角度只在导演阐述允许的地方使用。

## 焦段（物理摄影版）

焦段影响空间感和人物与环境的关系。不需要写死一个数字，但要写倾向和理由。数值是设计意图，不代表模型会执行。

| 倾向 | 效果 | 常用来 |
|---|---|---|
| 广角 | 空间被拉开，近处的物体显得大，靠近人脸时会变形 | 交代空间；表现压迫、混乱、失控；人与环境的关系 |
| 标准 | 接近人眼的透视，平实 | 客观的叙述；不想引起注意的镜头 |
| 中长焦 | 脸部比例好看，背景开始虚化 | 人物近景和特写的常用选择 |
| 长焦 | 空间被压缩，背景很虚，人物被从环境中隔离 | 窥视感；孤立；人群中的一个人；远处的追踪 |

同样的景别，用广角贴近拍和用长焦远远拍，感受完全不同。前者让观众身处其中，后者让观众远远地看。

## 景深

- **浅景深：** 只有主体清楚。把注意力锁在一个人或一件东西上，把他和环境隔开。
- **深景深：** 前后都清楚。让前景和背景同时说话，适合需要观众看清空间关系或两个人同时在场的镜头。

浅景深不是越浅越好。两个人同时在画面里并且都重要时，不能让其中一个虚掉；手和物件的交互，手和物件要在同一个清楚的范围里。

**移焦**是在镜头内把焦点从一个主体移到另一个，相当于不切镜头的切换。要写清楚：从谁移到谁，由什么触发。

## 构图

| 手法 | 效果 |
|---|---|
| 中心构图 | 稳定、正式、对峙；对称时显得受控或诡异 |
| 偏置加留白 | 视线方向留出空间，人物显得在看向某处；背后留白会让人不安，好像有东西会从那里来 |
| 前景遮挡 | 窥视感；增加纵深；把人物框住 |
| 框中框 | 门框、窗框、镜子把人物困住 |
| 引导线 | 道路、走廊、栏杆把视线引向主体 |
| 负空间 | 大面积空白，人物很小，孤独或压迫 |
| 层次 | 前中后景都有东西，画面有深度 |

**视线留白：** 人物看向哪边，哪边留出空间。对话的正反打，两边的留白方向相反，这样剪在一起时两人像在相互看。

**头顶空间：** 近景和特写不要在头顶留太多空，会显得人物在往下沉。情绪越紧，构图可以越满，甚至切掉头顶。

## 竖屏构图

竖屏的宽度很窄，横屏的很多习惯要改：

- **纵向分层取代横向并排。** 两个人不并排站，而是一前一后、一高一低，靠纵深表现关系。
- **单人为主。** 竖屏最擅长单人的近景。双人戏多用正反打和过肩，少用双人并排的中景。
- **上下的空间是资源。** 头顶的空间可以放环境信息，下方可以放手和道具。
- **字幕和平台界面占位。** 画面下方和右侧常被字幕、按钮、文案遮住，重要的内容放在中间偏上的安全区。具体范围以发布平台为准，记在项目配置里。
- **远景要克制。** 竖屏的远景里人物很小，需要更长的时间让观众看清，或用明显的动作、颜色引导视线。

## 运动

运动要有动机。没有动机的运动只是让画面在动，观众会感到不安或分心。

| 运动 | 效果 | 常见动机 |
|---|---|---|
| 固定 | 冷静、客观、克制；让表演说话 | 默认选择 |
| 推（摄影机靠近） | 逐渐聚焦，压力上升，进入人物内心 | 人物意识到某件事；情绪在积累 |
| 拉（摄影机远离） | 揭示更多环境；疏离；把人物留在原地 | 揭示真相；人物被抛下 |
| 横移、跟随 | 陪着人物走；流动感 | 人物在移动 |
| 摇 | 从一个东西转向另一个，像人转头 | 视线的转移；揭示 |
| 升降 | 视角高度的改变，常有仪式感 | 开场、结尾、情绪的升华 |
| 手持 | 不稳定、在场、慌乱、真实 | 混乱、追逐、人物失控 |
| 环绕 | 时间凝固，人物成为中心 | 关键时刻；关系的确认 |

**用法：**

- **固定是默认。** 先问这个镜头需不需要动，再问怎么动。
- **运动要写清楚：** 起点和终点（从哪个景别到哪个景别、从哪里到哪里）、方式、速度、持续多久。“缓慢推进”不够，“从中景推到近景，三秒，匀速”可以执行。
- **推和变焦不同。** 推是摄影机移动，空间关系在变；变焦是摄影机不动、焦段在变，空间被压扁或拉开。两者效果不同，要分开写。
- **运动要能完成。** 镜头的时长装得下这个运动，空间里有路可走，不穿墙穿车。
- **生成模型的运镜能力有限。** 复杂运动、长距离运动、多段运动组合，先看适配卡的已知弱点。做不好的改成固定镜头加剪辑。

## 镜头长度

- 观众看懂一个画面需要的时间，和画面的信息量有关。简单的特写一秒多就够；有很多信息的远景需要更久。
- 镜头越短，节奏越快，越紧张；镜头越长，越凝视，越让人不安或沉浸。
- 情绪的高点不一定要用短镜头。一个长时间不切的特写，常常比快速的剪辑更有力量。
- 时长要能装下台词、动作和反应，不能为了快节奏压缩台词。
