# 画面合同：物理摄影版

用于真人短剧和 3DCG 动画。这两种形态有真实或虚拟的摄影机，镜头、景深、布光的概念适用。

画面合同规定每个镜头要写清哪些画面信息。它的目的是让设计意图从分镜一路完整传到生成请求和验收，不在中间丢失。

## 分级填写

字段分三级。这样做是为了把力气花在真正影响画面的地方，而不是为了显得详细去编数字。

**场级预设：** 画面预设表里的内容（色彩、影调、主光来源与方向、默认焦段倾向、默认景深、默认运动方式、质感）在场头引用一次。逐镜只写与预设不同的地方。

**必填：** 每个正式镜头都要有，没有就不能提交。

**视情况：** 这个镜头涉及时才填，例如有运动才写运动，有移焦才写移焦。不涉及写“无”。

**选填：** 模型通常无法直接执行的物理参数。有明确设计意图时可以填，但要同时写出它应该产生的可见效果。不要为了显得专业而编造。

## 字段

### 必填

| 字段 | 写什么 | 合格的例子 |
|---|---|---|
| 镜号与来源 | 镜号、源段落编号、引用的画面预设编号 | EP01-S03-C05，P014 至 P015，LOOK-02 |
| 叙事目的 | 这一镜要让观众知道或感到什么 | 让观众先于她看到门缝下的影子 |
| 景别 | | 近景 |
| 机位 | 在场景的哪一侧、相对眼睛的高度、俯仰、在轴线的哪一侧 | 窗户一侧，略低于她的眼高，微仰，轴线右侧 |
| 焦段倾向 | 广角、标准、中长焦、长焦，以及为什么 | 中长焦，把她从凌乱的背景中隔开 |
| 焦点与景深 | 焦点在谁身上，哪些东西必须同时清楚，背景虚到什么程度 | 焦点在她的眼睛，手里的信封也要可辨，背景的门轮廓可见 |
| 构图 | 主体在画面的位置和大小、视线方向的留白、前景、背景元素 | 人物在画面左三分之一，视线向右，右侧留白；前景是虚化的台灯 |
| 起始画面 | 镜头开始时谁在画面里、在哪、什么姿势、朝向、看哪里、手里拿着什么 | |
| 表演 | 按表演链写：触发、主动作、结束状态 | |
| 台词与声音 | 完整的确认台词、说话人、类型、语气与停顿；本镜的环境声与动作声 | |
| 时长与依据 | 秒数，以及由台词、动作、反应、停顿怎么算出来的 | 4 秒：台词 2.5 秒，前停顿 0.5 秒，后反应 1 秒 |
| 结束状态 | 镜头结束时人物、道具、视线、焦点的状态；声音的尾点；如何接下一镜 | |
| 资产 | 本镜用到的资产编号和版本，均在白名单内 | |

### 视情况

| 字段 | 什么时候填 | 写什么 |
|---|---|---|
| 运动 | 摄影机移动、摇、变焦时 | 类型、起点和终点（景别或位置）、速度、持续时间、动机。推轨和变焦分开写 |
| 移焦与跟焦 | 焦点在镜头内变化时 | 从谁到谁，由什么触发，在第几秒完成 |
| 光线变化 | 与场级预设不同时 | 本镜的主光方向（按空间换算后的）、受光面、补光与暗部、轮廓光、眼神光 |
| 道具交互 | 有拿取、使用、交接时 | 哪只手、接触点、动作过程的关键节点、道具的起止状态 |
| 特殊效果 | 慢动作、定格、画面内的光效等 | 效果及其目的 |

### 选填

| 字段 | 说明 |
|---|---|
| 焦距数值（毫米） | 写数值时注明等效基准，并写出期望的透视效果 |
| 光圈数值 | 写数值时同时写出期望的景深效果 |
| 拍摄距离 | |
| 机位的精确高度和角度 | |
| 快门、帧率与运动模糊 | |
| 色温数值、曝光、亮暗部的相对关系 | |
| 灯光的精确位置和强度比 | |

这些数值是设计值，不是测量值，也不代表模型会执行。生成模块翻译请求时，模型不支持的会改写成可见效果，并标“仅视觉约束”。

## 字段之间的相容检查

填完后检查字段之间有没有矛盾：

- **焦段、距离、景别：** 广角做特写意味着摄影机离脸很近，脸会变形，这是不是想要的？
- **景深与需要同时看清的东西：** 浅景深下，两个人或手和物件能同时清楚吗？
- **运动与时长：** 时长装得下这个运动吗？运动的路线在空间里走得通吗？
- **动作与构图：** 人物站起、转身、走动时还在画面里吗？固定的紧特写里人物不能大幅移动。
- **光线与空间：** 主光方向是从场景的实景光源换算来的吗？反打时有没有简单复制成同一侧？
- **曝光：** 有没有同时要求互相矛盾的亮暗关系？

有矛盾的镜头先修改，再提交。

## 不合格的情况

以下情况的镜头退回修改，不能标为可提交：

- 必填字段缺失，或用“电影感”“自然”“缓慢”“合适的”代替具体内容。
- 确认的台词被删减或改动。
- 表演只有形容词。
- 起始画面与上一镜的结束状态矛盾。
- 光线方向与场景光源和机位不符。
- 景深会模糊掉必须看清的东西。
- 动作在时长内完成不了，或会离开画面。
- 引用了白名单以外的资产。

字段齐全不等于设计正确，最终要看生成出来的画面。
