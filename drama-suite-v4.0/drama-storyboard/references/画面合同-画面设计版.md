# 画面合同：画面设计版

用于 2D 动画和漫剧。这两种形态没有真实的摄影机，画面由画法、构图和画面上的运动决定。焦距、光圈、快门这类摄影参数不适用，硬套会让模型困惑，也让设计失焦。

景别、角度、构图、视点、轴线、视线、表演、连续性的原则与物理摄影版相同，见 [镜头语法](镜头语法.md) 和 [场面构建与连贯](场面构建与连贯.md)。本合同只替换与摄影机物理特性有关的部分。

## 分级填写

与物理摄影版相同：场级预设引用一次，逐镜写变化；字段分必填、视情况、选填。

场级预设来自画面预设表的画面设计版：色彩、明暗、光影表现方式、线条、上色方式、背景处理、构图倾向、默认的画面运动、帧感、效果表现、质感。

## 字段

### 必填

| 字段 | 写什么 | 合格的例子 |
|---|---|---|
| 镜号与来源 | 镜号、源段落编号、引用的画面预设编号 | |
| 叙事目的 | 这一镜要让观众知道或感到什么 | |
| 景别 | | 特写 |
| 视点与角度 | 从哪里看、俯仰、在轴线的哪一侧 | 从门口方向，略俯视 |
| 透视 | 透视的强弱，消失点的位置 | 弱透视，接近平面，消失点在画面外右侧 |
| 构图 | 主体的位置和大小、留白、前景、背景元素 | 人物占画面下半部，上方大片暗色留白 |
| 主体与背景的关系 | 背景是精细、简化、虚化、纯色还是抽象化；主体如何从背景中分离 | 背景简化为色块并压暗，人物用轮廓光分离 |
| 起始画面 | 谁在画面里、在哪、什么姿势、朝向、看哪里、手里拿着什么 | |
| 表演 | 按表演链写；漫剧注明用哪张立绘和差分 | 漫剧：立绘 A，表情差分从“平静”换到“怔住” |
| 台词与声音 | 完整的确认台词、说话人、类型、语气与停顿；环境声与动作声 | |
| 时长与依据 | | |
| 结束状态 | | |
| 资产 | 本镜用到的资产编号和版本 | |

### 视情况

| 字段 | 什么时候填 | 写什么 |
|---|---|---|
| 画面运动 | 有推拉摇移时 | 类型、起止的范围、速度、持续时间、缓入缓出、动机 |
| 分层视差 | 需要纵深感时 | 分几层，各层的移动方向和相对速度 |
| 人物动作 | 2D 动画中人物有动作时 | 动作的关键姿势、帧感（流畅或保留停顿） |
| 光影变化 | 与场级预设不同时 | 光从哪里来，阴影的方向和层数，高光的位置 |
| 效果表现 | 用速度线、冲击帧、光效、情绪符号时 | 用什么，在哪一刻，持续多久 |
| 分格与转场 | 漫剧使用分格、斜切、出框、翻页式转场时 | 格的形状和排列，转场的方式 |
| 画面上的文字 | 有拟声词、手写文字、信息卡时 | 内容、位置、样式。准确文字归后期排版 |

| 字段 | 说明 |
|---|---|
| 线条的局部变化 | 例如情绪激烈时线条变粗、变抖 |
| 色彩的局部变化 | 例如回忆用褪色或单色 |
| 精确的运动曲线 | |

## 漫剧的特别要求

漫剧的画面运动少，叙事更多依赖构图、配音和节奏。

- **构图要承担更多。** 每一格的构图本身要有表现力：角度、留白、前景、明暗对比。
- **画面运动要有节制和目的。** 推拉摇移是漫剧的主要运动手段，不要每一格都在动。动的时候要有动机：推向人物是聚焦，摇过画面是揭示。
- **差分的切换就是表演。** 表情差分的切换时机对准台词的情绪点，并留出观众看清的时间。
- **声音和旁白的比重更大。** 配音的节奏决定画面的节奏。时长依据以配音为主。
- **口型可省。** 按形态档案的规定，口型可以简化或不做，但说话人的身份要清楚。

## 相容检查

- 透视与构图：透视强弱是否与镜头的情绪目的一致？
- 画面运动与时长：时长装得下这个运动吗？速度是否让观众看得清？
- 分层视差：各层的风格是否一致，移动时会不会露出画面的边缘？
- 表演与资产：需要的立绘和差分在白名单里吗？
- 光影与场景：光影方向是否符合场景的光源设定？

## 不合格的情况

- 必填字段缺失，或用形容词代替。
- 套用了焦距、光圈这类不适用的参数，却没有写构图和透视。
- 确认的台词被改动。
- 画面运动没有动机，或每一镜都在运动。
- 表演只有形容词；漫剧没有指定立绘和差分。
- 起始画面与上一镜的结束状态矛盾。
- 引用了白名单以外的资产。
