# 表演指导

AI 生成的人物最常见的问题不是不像，而是不在演：站在那里说话，脸上有一个表情，但没有因果、没有变化。表演指导的任务，是把剧本里的情绪变成模型可以执行的、看得见的动作。

表演的整体风格以导演模块的表演基调为准：写实程度、默认幅度、每个人物的表演关键词。

## 表演链

每一镜的表演按这个链条写：

1. **触发：** 什么引起了反应？一句话、一个声音、看到某样东西。
2. **接收：** 视线的变化或一个停顿。人物先接收到信息，然后才反应。这一拍常被省略，正是它让表演显得真实。
3. **主动作：** 人物做了什么。
4. **结果：** 动作带来的改变：道具的状态，对方的反应，人物自己的位置。
5. **余波：** 动作之后残留的东西：呼吸的变化，手没有放下，视线没有收回。

不是每一镜都要五步写全。但至少要有触发和主动作，并且说清楚这一镜结束时人物处于什么状态。

## 用动词，不用形容词

| 不能执行 | 可以执行 |
|---|---|
| 她很伤心 | 她低下头，手指慢慢抠着杯沿 |
| 他很愤怒 | 他把文件合上，没看对方，推回到桌子中间 |
| 两人很尴尬 | 两人同时开口，又同时停下；她先移开视线 |
| 她很震惊 | 她的手停在半空，过了一拍才放下 |
| 他在思考 | 他的视线落在桌上某一点，手指在桌面上停了下来 |

**情绪要有载体：** 呼吸、吞咽、视线、手、肩膀、一件被拿起或放下的东西。观众看不到情绪本身，只能看到情绪留下的痕迹。

## 少即是多

- **每镜一个主要动作。** 不要在一个镜头里堆满眨眼、皱眉、叹气、握拳。动作越多，模型越容易乱，观众也越不知道该看什么。
- **默认用小的。** 微表情和眼神比大幅度的表情更容易做好，也更耐看。把大的动作留给情绪的最高点。
- **克制比释放更有力。** 一个人强忍着不哭，比放声大哭更打动人。观众会替他把情绪补上。
- **不为细腻而细腻。** 不是每一镜都要安排手指的颤动或眨眼。只有在这个细节有意义时才写。

## 反应

- 说话的人只是这场戏的一半。听的人怎么接收这句话，往往才是戏。
- 每一句关键的台词，都要考虑对方的反应镜。
- 反应要具体：听到坏消息的人，第一反应可能不是悲伤，而是否认、愣住、问一个无关的问题。
- 同框的其他人，要么有一个具体的反应，要么保持一个明确的持续状态（在低头看手机、在擦桌子）。不能像背景板一样静止。

## 台词与表演

- 写清楚这句话怎么说：语气、停顿在哪里、重音在哪个词。
- 写清楚说话时人物在做什么。人很少只是站着说话。
- 动作和台词可以相反：嘴上说没关系，手上在攥紧衣角。这是潜台词在画面上的样子。
- 对白镜头保证脸、眼睛、嘴可以看清。
- 多个说话人不要塞进同一个需要口型的镜头。口型同步一次只做好一个人。

## 写给模型的注意事项

- 动作要有清楚的起点和终点。“她转身”不够，“她从面向窗户转到面向门，停下”可以执行。
- 动作要在镜头的时长内完成，并且留在画面里。人物会站起来或走动时，构图要给他留空间，或者运镜跟随，或者拆成两个镜头。
- 手部的精细动作、身体的接触、吃喝，参照剧本的可制作性审查和适配卡的已知弱点，用局部、遮挡或结果代替过程。
- 一个镜头里的情绪变化不宜太大太快。从平静到崩溃需要过程，可以拆成多个镜头。

## 自查

- 每镜写了触发和主动作，以及结束时的状态。
- 没有只写形容词的表演。
- 关键台词有对方的反应镜。
- 同框的人都有事做。
- 表演幅度符合表演基调，大的动作留给了最高点。
- 动作能在时长内完成，并留在画面里。
