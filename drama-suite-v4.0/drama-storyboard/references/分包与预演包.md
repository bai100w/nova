# 分包与预演包

一集的逐镜设计完成后，做两件事：做预演，在花钱之前检查这一集是否成立；按生视频模型的能力，把镜头分成生成包。

## 预演

预演分三层，按档位决定做到哪一层：

| 层 | 做法 | 成本 | 小样 | 标准 | 精品 |
|---|---|---|---|---|---|
| 纸面预演 | 预演清单、时间线、结构检查、盲读测试 | 只有 token | 必做，可不做盲读 | 必做 | 必做 |
| 文字卡预演片 | 脚本从预演清单自动生成，文字卡加台词加临时音乐 | 几乎为零 | 不做 | 环境支持就做 | 必做 |
| 关键镜头静帧 | 只给钩子、最高点、高风险镜头生成静帧 | 少量生图费用 | 不做 | 只做高风险镜头 | 钩子、最高点、高风险镜头 |

纸面预演的做法见 [纸面预演](纸面预演.md)。文字卡预演片由剪辑模块组装，见 [动态预演组装](../../drama-editing/references/动态预演组装.md)。

**关键镜头静帧：** 按画面卡生成，花钱时按共用规则确认授权。生成的静帧填进预演清单的“图片”列，文字卡预演片会自动用图片替换文字卡。静帧通过后可以作为视频生成的首帧候选，但要重新核对资产的一致性，不能直接当作已验收的素材。

预演发现的问题回到分镜修改，只重新检查受影响的部分，然后交总控过预演关卡。

## 生成包

### 分包依据

剪辑镜头和生成包是两回事，分开编号：

- 一个生成包可以包含多个剪辑镜头（子镜）。
- 一场戏可以跨多个生成包。

怎么分，取决于生视频模型的适配卡：单次生成的时长上限、参考图数量上限、是否支持多镜头、是否支持首尾帧。适配卡未核验时，分包标为“暂定”。

**分包原则：**

- **同场、连续、同一组人物和场景的小镜头，尽量合并到一个包。** 减少请求数量，也让包内的一致性更好。
- **不按每句台词或每个说话人机械拆包。**
- **包的时长装得下内容。** 装不下就拆包，不删台词、不加速。
- **高风险镜头单独成包。** 可制作性审查标为高风险的镜头，单独成包，方便重试而不连累其他镜头。
- **需要不同参考组合的镜头分开。** 参考图数量有限时，按需要的资产组合来分。

### 每个包写什么

用 [生成包模板](../templates/生成包模板.md)。每个包要能独立执行，不依赖其他包或聊天里的内容：

- 包编号，包含的子镜编号
- 包内时间轴：每个子镜从第几秒到第几秒
- 子镜时长合计，请求的时长，余量做什么用
- 包开始和结束时的状态（从连续性状态表来）
- 依赖：是否需要上一个包的结尾作为首帧
- 需要的资产：每个文件、控制什么、用于哪个子镜
- 完整的执行内容：所有子镜的起始画面、表演、画面合同的字段、完整台词、声音、切点
- 项目的负面约束

共用的规则可以在包内写一次，但必须写在包里。不能写“同上”“见上一包”。生成模块会把它翻译成模型的请求，翻译时也不能把详细的内容缩成一句梗概。

### 资产核对

每个包提交前，按资产模块 [拆解与登记](../../drama-assets/references/拆解与登记.md) 的“逐包核对”四步检查：清单、文件、内容、附带。每项标：已核对可提交、待用户确认、缺失。有缺失的包不能提交。

## 连续性状态表

跨包追踪每个人物和关键道具的状态。每个包一行，记录包开始和结束时：

| 项 | 内容 |
|---|---|
| 人物 | 身份、年龄阶段、造型 |
| 位置与姿势 | 在场景的哪里，站、坐、蹲，朝向 |
| 视线 | 看向哪里 |
| 手 | 哪只手拿着什么 |
| 道具 | 位置与状态 |
| 声音 | 谁在说话，用哪个声线 |
| 光与时间 | |

**规则：**

- 下一个包的开始状态，等于上一个包**实际生成并通过审片**的结束状态，不是计划的结束状态。
- 生成后实际结果和计划不同时，更新这张表，并检查后续的包是否需要调整。
- 用作续接的片段必须已经通过审片。待审的、被否定的、有连续性错误的片段不能用来续接。

## 修订

- 台词变了：重算时长和分包。
- 动作变了：检查接镜和需要的资产。
- 风格变了：更新受影响的镜头和包。
- 资产变了：逐包重新核对。
- 修订时标明哪些镜头可以保留、哪些需要补、哪些需要返修。重新设计不等于整场重新生成，只返修受影响的部分。

## 四种状态分开记录

每个包分别记录：设计复核、素材就绪、请求适配、成片验收。不用一个“完成”混在一起。
