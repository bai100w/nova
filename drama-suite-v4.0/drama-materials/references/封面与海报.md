# 封面与海报

## 封面的任务

在信息流里，观众用一秒决定点不点。封面要在这一秒里回答：这是什么样的故事，为什么现在就要看。

## 选什么画面

按优先顺序考虑：

1. **冲突的瞬间。** 两个人物对峙，一方处于劣势，一个关键物件被揭示。观众能看出有事情正在发生。
2. **强烈的情绪。** 一张情绪清楚的脸：震惊、愤怒、隐忍、绝望。人脸是信息流里最抓眼睛的东西。
3. **反常的画面。** 一个需要解释的画面，和剧本的开场钩子同理。
4. **关系的张力。** 两个人的距离、姿态、视线，能看出他们之间的关系。

选题来自这一集的节拍表：强度最高、最能代表这一集的节拍。但不要选反转的结果，那是剧透；选反转之前、问题最尖锐的时刻。

## 构图

- **主体大。** 人物的脸或上半身占画面的大部分。缩小后背景几乎看不清，只有主体能看清。
- **一个视觉重点。** 观众的眼睛第一眼落在哪里，由大小、明暗、颜色、位置决定。只设计一个重点。
- **层级清楚。** 第一眼看人物和表情，第二眼看标题，第三眼看细节。
- **简化背景。** 背景压暗、虚化或简化，给主体和标题让出位置。
- **留出标题的位置。** 构图时就决定标题放在哪里，不要等画面做好了再找空。避开人脸、手和关键物。
- **避开平台界面。** 信息流封面上会叠加时长、按钮、文字。重要内容放在不会被遮住的区域，范围以发布平台为准。

## 颜色和光

- 封面的颜色和视觉圣经一致，同时可以比正片更饱和、对比更强，以便在信息流里跳出来。
- 用光把主体和背景分开：主体亮、背景暗，或主体有轮廓光。
- 主角的归属色可以作为封面的主色，让系列封面有统一的识别。

## 系列一致

连载的封面要有统一的识别，让观众一眼认出是这一部：

- 标题的位置、字体、样式统一。
- 色调统一，或按固定的规则变化（例如每一季一个主色）。
- 构图的方式统一（例如始终是人物特写加右上角标题）。

在第一集的封面确定后，把这些规则写进 `patterns/materials.md`。

## 制作

简单的封面可以一步完成。复杂的海报分步处理，每一步可追溯：

1. **角色素材。** 用已确认的身份和造型资产。需要特殊姿势或造型的，登记为物料变体。
2. **构图底图。** 场景、背景、空间关系。
3. **人物融合。** 把人物放进底图，统一透视和比例。
4. **色彩和光线统一。** 让人物和背景看起来在同一个光线环境里。
5. **文字排版。** 用可编辑的方式加标题和文字。

用生图模型时，按适配卡写请求，花钱时先确认授权。

## 尺寸

一张主视觉通常要出多个尺寸。不要简单裁切：横版改竖版时，人物和标题的位置要重新安排。每个尺寸单独检查。

## 检查

- 缩小到信息流的实际大小，还能看清人物的表情和标题吗？
- 第一眼看到的是不是想让人看到的？
- 人物的脸、造型、比例和正片一致吗？
- 有没有展示正片里没有的东西？
- 标题和文字有没有错字，有没有被平台界面遮住？
- 剧透的程度符合要求吗？
- 和系列的其他封面放在一起，统一吗？
