# 标题与文案

## 标题

标题和封面一起工作。封面给画面和情绪，标题给信息和问题。两者不重复，互相补充。

### 有效的标题

- **具体。** 具体的人物、具体的处境、具体的数字。“她的复仇”不如“被逐出家门的第三年，她回来收购了整个家族”。
- **有问题。** 让人想知道答案：结果是什么，为什么会这样，接下来会怎样。
- **有反差。** 身份的反差，处境的反差，预期的反差。
- **兑现题材的承诺。** 读完能感到这是哪一类的故事，对得上题材档案的观众承诺。

### 常用的结构

| 结构 | 做法 |
|---|---|
| 处境加转折 | 一个困境，加一个出人意料的行动或结果 |
| 身份反差 | 表面的身份和真实的身份 |
| 悬念 | 一个关键的问题，不给答案 |
| 倒计时或代价 | 期限，或者失败的代价 |
| 关系 | 两个人之间不寻常的关系 |

### 不要做的

- 用正片里没有的情节做标题。
- 剧透反转的结果。
- 夸大到成片撑不住：“史上最虐”“全网都在看”。
- 堆砌感叹号和网络流行语，看起来像所有其他标题。
- 违反平台的规范。

## 简介

简介是给已经被封面和标题吸引、想多了解一点的人看的。

- 第一句是最重要的信息：主角是谁，处境是什么。
- 交代核心冲突，不交代结果。
- 篇幅以平台为准，通常越短越好。
- 连载的简介，交代这一集在主线里的位置，但不让没看过前面的人看不懂。

## 发布文案

发布时配的文字，用来引发评论和转发：

- 可以抛出一个问题，让观众站队：“如果是你，你会原谅他吗？”
- 可以点出这一集最有争议或最触动人的地方。
- 语言和口吻符合目标平台和观众。
- 不剧透关键的反转。

## 多个方案

标题和文案每次给三到五个方案，用不同的结构，标明各自的思路。由用户选择，或在平台允许的情况下做测试。选中的方案和效果记下来，作为 `patterns/materials.md` 的依据。

## 本地化

目标市场是另一种语言时，标题和文案要重新写，不是直译。同样的钩子在另一种文化里可能需要不同的表达。按目标市场处理称谓、幽默和文化背景。

## 检查

- 读完想点进去吗？
- 和封面是互相补充，还是在重复？
- 成片撑得住这个标题吗？
- 有没有剧透？
- 有没有错字？
- 符合平台的规范吗？
