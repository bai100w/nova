# 漫剧自动剪辑学习计划

## 目标

把外部案例、剪辑成片和用户反馈转化为可复用但不僵化的决策规则，让下一次剪辑更会服务剧情，而不是更会堆效果。

## 四阶段循环

### 阶段 1：方法研究（已完成，2026-10-01）

研究公开的短剧/漫剧剪辑 skill、剪映自动化能力、平台竖屏规范和剪辑基础方法。产物：`research-notes-2026-10-01.md`。

### 阶段 2：规则蒸馏（已完成，2026-10-01）

把研究拆成可执行的可用带、入出点、节奏、转场、BGM、花字、放大和验收规则，分别写入本 skill 的参考文件。只保留能解释“何时用、为什么用、何时不用”的方法。

### 阶段 3：项目验证（每个项目第一次剪辑时执行）

先用适当范围的已验收素材形成可审查决策单，检查素材选取、台词可懂性、节奏、字幕、BGM方向和包装是否符合本剧。已有明确制作授权就按范围继续建草稿及验证；尚未授权制作或只要方案则止步于方案。不把一次测试判断推广为所有项目。

### 阶段 4：成片复盘与入库（每次用户反馈后执行）

把“哪一段有效/无效、为什么、修改了什么、适用范围、例外”写进当前项目 `漫剧数据库/references/REF-日期-序号.md`。用户说“入库”“锁定”“以后这样做”后，再写入项目 `patterns/` 和更新日志。跨项目的共性方法先检查是否与本 skill 冲突，再更新本 skill；具体角色、视觉、音乐、台词和平台资产不得写入通用规则。

## 学习纪律

- 观察到一个好效果，不等于知道它由什么造成；视频未完整观看时不臆测剪辑、音频或镜头参数。
- 只借鉴抽象方法，绝不复制参考作品的角色、台词、完整镜序、音乐、字体或素材。
- 用户最新明确的项目决定优先于通用规律。
- 每一轮新学习都要说明：来源事实、推断、可迁移规则、不迁移内容、置信度和影响范围。
