# 剪映 CLA / JyWrapper 执行交接

本 skill 负责剪辑决定；真正建立草稿时调用现有 `jianying-editor` skill，并遵守它的草稿、媒体、文字、关键帧、效果、声音和导出规则。业务脚本及检查输出放在当前项目导航规定的工具目录；无相关规则时再选项目内 scripts 目录，不写入任何 skill 安装目录。

## 交接前最小清单

1. 可审查剪辑决策单：所有 `CUT-` 都有真实来源、可用带、入出点与理由，重点 `BEAT-` 有音画字配合规格。按已有制作授权执行，不重复要求确认同一许可。
2. 项目配置：画幅、帧率、字幕/花字开关、音频许可、导出路径、目标平台安全区。
3. 已授权素材：视频、角色对白、BGM、环境声、音效、字体/花字样式的绝对路径或真实平台 ID。
4. 轨道规划：画面、对白、环境、BGM、音效、字幕、花字/信息卡分别命名，禁止把 BGM 放入视频轨。

## 执行约束

- 工程宽高与帧率按项目配置；1080x1920仅是竖屏示例，不能覆盖720p、4K等指定规格。改变素材画幅时先写明裁切、留白或重构图决定。
- 使用 `JyProject`、`add_media_safe()`、`add_audio_safe()`、`add_text_simple()`、`add_styled_text()` 和关键帧能力时，以当前 `jianying-editor` 实际支持的 API 为准；执行前检查方法存在。
- 调用平台花字模板、转场、滤镜和特效时，先通过 `asset_search.py` 获取实际素材ID；自制文字动画记录字体、样式及实际关键帧，不要求不存在的平台模板ID。不能猜ID，不能以伪代码表示为已执行。
- 关键帧的时间单位、起止、缩放幅度和安全区必须与剪辑决策单一致；不是所有视频段都需要关键帧。
- 先生成剪映草稿，检查视频轨、音频轨、字幕轨和保存结果。已有成片导出授权时继续导出；只授权方案或草稿时按范围交付。导出后检查文件存在、画幅/帧率、时长、首尾帧和声音。

## 失败处理

草稿保存成功不代表剪辑正确。若 API、效果或导出失败，保留脚本和草稿状态，报告失败步骤、实际错误、受影响的 `CUT-` 与未完成项。不要用手工猜测 JSON 或重复覆盖原草稿来掩盖失败。
