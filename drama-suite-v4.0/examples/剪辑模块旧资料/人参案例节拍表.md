# 人参 demo：可复用的节拍关系

学习日期 2026-10-17。原片约 30.04 s / 24 fps；既有导出约 34.97 s / 30 fps。主叙事的 13 次切换均对应原片，后期价值主要在声音编排、局部构图曲线、字幕与尾声。以下是本例证据，不是所有漫剧的默认参数。

证据分层：UI = 当前草稿可见设置；帧 = 原片/既有导出的真实帧对照；波形 = 实际缓存音源与导出连续窗口匹配；解释 = 对叙事作用的分析。当前草稿与旧导出的完整音画版本一致性未验证，不能拼成精确当前工程 EDL。本轮不能输入试听音频，音色、遮词、音乐乐句和主观冲击感未听审。

## 真正应迁移的是速度与包络

| 项目 | 本例读数 | 怎样复用 |
|---|---|---|
| 道具缩放 | 图像拟合4.233 s100% → 4.400 s约115% → 5.900 s约120%；UI4.900 s117%、X0/Y192 | 快到位后慢推，配合位置保留道具；曲线由新素材构图决定 |
| 男脸强调 | 图像拟合9.900 s100% →10.033 s约110%，保持至切镜 | 短推后停住，不每个字都缩放 |
| 分离声轨 | UI第一段人声“仅保留人声”+20 dB；背景“仅保留背景声”+13.6 dB | 学独立控制，不抄增益；要查原声重复和分离伪影 |
| 中段音乐 | 華の乱UI -13.1 dB、淡入1.0 s、淡出0 s | 选适合实际对白的音量；与下一曲交叠并不证明双方都做了淡出 |
| 尾段音乐 | 紧张氛围配乐3 UI +4.5 dB、淡入1.1 s、淡出1.5 s | 段落先铺底，短声再加事件，尾部独立退场 |
| 转场/闪光音效 | UI呼转场+9 dB；第一处闪光+20 dB | 只作取证值；素材自身响度不同，不能据增益比较谁更响 |
| 聚焦抖动 | UI速度50 | 这是效果参数，不是50Hz或振幅50%；保留已核名称，迁移时查当前可用资源 |

图像拟合不是读出的关键帧值/缓动类型；相关高只支持结果接近。不要把 UI 某时刻的117%写成整段固定117%。

## 字幕与花字应分开学习

已观察到10条双语整句字幕，英文在上、中文在下、白字深色轮廓；按句硬入硬出，部分跨切镜1–4帧。查看的一句英文UI为新青年体、字号8、入场无；不能代表所有句子参数，也不能跨工程复制字号。

本片没有独立剧情强调花字。片尾三行是署名字卡，入场“向右模糊II”0.9 s，不能拿来证明主体使用了爆炸字。迁移到需要花字的新片，依据 [字幕与包装](captions-and-packaging.md) 设计关键词，并用 [音画节拍](impact-and-rhythm.md) 同步，标为新增方案。

可学之处是字幕跟句意、信息先于反应、字卡先动后稳。要改进之处是尾部特效曾使对白字幕模糊，新片应优先保证可读；英文识别/翻译问题也不复制。

## 不能当成优良预设的部分

既有导出测得综合响度约 -10.41 LUFS、真峰值约 +0.88 dBTP；原片约 -17.52 LUFS、-2.30 dBTP。测量不能证明听起来已削波或更好听，但正真峰值是输出处理需复核的项目。参考的高增益、字幕小字和末段字幕模糊不是学习目标。
