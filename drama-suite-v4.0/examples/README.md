# 案例库

这里是旧项目留下的具体做法，仅供参考，不是规则，也不是默认值。

- 这些文件不是 skill，不会被自动加载。
- 里面的画幅、字幕开关、音乐取舍、角色、数值，都只属于原项目，不能带进别的项目。
- 想借鉴某个案例的做法时，先判断它适不适合当前项目的形态、时长和题材，再把适用的部分写进当前项目的资料库。

| 案例 | 内容 | 原出处 |
|---|---|---|
| `恋综自动流/` | 为一个恋综项目定制的自动推进流程 | 旧版 drama-autoflow v1.2 |
| `黄海项目约束.md` | 一个项目的生成负面约束，以及由它总结出的通用做法 | 旧版 drama-storyboard、drama-production |
| `剪辑模块旧资料/` | 人参案例节拍表、剪辑决策压力测试、学习计划、研究笔记、旧版剪映执行交接 | 旧版 drama-editing v3.2 |

旧版文件里指向其他模块的链接是当时的路径，现在可能已经失效。
