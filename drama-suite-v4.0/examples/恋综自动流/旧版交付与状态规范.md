# 交付与状态规范
## 目录与编号
资料用 `漫剧数据库/`，原素材留在 `资产/`。按需建 `制作/EP01/01_剧本/`、`02_分镜/`、`03_制作包/包ID_vN/`、`04_生成/`、`05_审片/`、`06_剪辑/`、`07_宣发/`。
源段落 EP01-S01-P001，生成包 EP01-S01-G01，子镜 EP01-S01-G01-01；已有编号优先，版本另列。
## 字段与状态
记录任务ID、集、阶段、源版本、输出版本、相对路径、状态、确认来源、验收证据、阻断、下一步和时间。状态：未开始、草案、待确认、就绪、执行中、待审、通过、需返修、阻断、停用。就绪不是提交，生成成功先记待审，文档合订不等于成片通过。
请求另记模型/参数核验日期、全文请求、实际附件及用途、任务ID、费用、输出、重试及原因。台词表保留段落、说话人、类型、原文、表演文本、确认状态；翻译另列。
资产记录ID、路径、SHA256、种类、角色/场景、版本、前版、控制维度、场次、状态和确认依据。文件存在仅代表已盘点。
## 质量关卡
1. 源稿：逐段逐字检查文字、顺序、说话人，屏幕字不误作口播。
2. 设计：环境空间、动作反应、独立表演、摄影光线声音与连续性可执行。
3. 素材：实际查看并确认身份、服装、比例、场景和声音，逐包核对实际附件。
4. 请求：实际发送全文含子镜及约束，参数核实、授权适用，包内依赖可读。
5. 成片：实际看听，逐切点逐句检查；无法检查的内容标未核验。
6. 交付：剪辑与决策单一致，字幕音乐封面按项目选择，导出规格实测，源文件可追溯。
## 恢复与制作包
中断前记录最近步骤、外部任务ID、文件和下一步；恢复先查任务避免重复付费。变更列受影响ID，只返修相关范围。
最终包物理包含源稿、映射、确认台词、全分镜、白名单、必要确认素材副本、声音/模型配置和读取说明。核心设计未确认只称候选包。平台引用登记本地文件与平台ID。
