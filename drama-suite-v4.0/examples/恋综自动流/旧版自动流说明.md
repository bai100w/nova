# 恋综漫剧自动流
规则版本：v1.2（资产先行与影视摄影核查）。

## 影视摄影检查
按 [逐镜摄影参数合同](../drama-storyboard/references/逐镜摄影参数合同.md) 将资产布局、影视光影标定、正式镜头分别验收；分镜和请求必须有完整摄影卡，不以“电影感”代替参数，也不以参数齐全替代实际效果。五类资产关卡未通过时只做当前允许的资产/风格测试，不展开正式全片分镜。

## 总控关卡与模块派工
执行前读 [资产先行与模块派工规范](../drama-control/references/资产先行与模块派工规范.md)。依次执行“剧本逐段拆解→五类资产总表→资产制作及实际验收→总控资产关卡→正式分镜→制作包/请求→生成审片→剪辑→宣发”。检查角色、场景、道具、风格对标、声音全部必要项；资产关卡未通过时只路由资产补齐，不展开全片正式分镜、锁定时长/生成包或视频生成。风格认可不扩大为其他资产验收，已有授权不重复审批。

## 开始与续做
1. 以本项目 AGENTS.md 所在目录为根，读 `漫剧数据库/项目索引.md`、`项目设定.md`、`制作状态.md`。缺索引时按同级 `drama-control/references/项目数据库框架.md` 初始化九类槽位。
2. 识别目标集、阶段终点、授权范围和已有确认。未指定集且无进行中任务时先盘点，不自行锁定首集；只要求搭建 skill 时止于搭建验证。
3. 接续最近有效版本，按需读取相关模块 SKILL.md 及必读参考。不以“终版”“定妆图”“V2”推定批准。每步回写路径、版本、状态、证据、阻断及下一步。
4. 恢复先查现有文件和外部任务ID，避免重复生成或付费。
## 阶段编排
按依赖顺序执行至用户指定终点；采用模块规则不等于默认创建子 agent。

| 阶段 | 同级模块 | 交付及通过条件 |
|---|---|---|
| 盘点路由 | drama-control | 九类槽位有入口，任务及来源明确 |
| 参考学习（按需） | drama-learning | 分清观察、推断、采用状态，封面不代替视听分析 |
| 剧本台词 | drama-script | 源段落ID、完整逐段映射、台词及说话人；按需本地化 |
| 五类资产制作验收 | drama-assets → drama-control | 全剧总表覆盖角色、场景、道具、风格对标、声音；必须项实际文件与看听验收齐备，总控关卡通过 |
| 分镜分包 | drama-storyboard | 环境动作覆盖、独立表演栏、摄影光线声音、完整台词、时长依据和包级附件表 |
| 制作包生成 | drama-control → drama-production | 包内物理包含确认源稿、映射、分镜、白名单及必要确认素材副本；核对实际请求后提交 |
| 审片返修 | drama-production | 实际看听，逐切点查脸比例姿态，逐句查台词声线，定向返修留版本 |
| 剪辑包装 | drama-editing | 已验收素材、可执行决策单，按授权建草稿、导出并验收 |
| 宣发归档 | drama-materials → drama-learning | 本集一致的封面文案，来源版本规格可追溯，只沉淀有证据的规律 |

资产阶段可迭代需求示意与风格测试，不提前展开全片正式分镜。已有分镜草案留为历史待复核，资产齐备后重新编排。无参考需求时仍核对本项目风格基准，不省略五类覆盖检查。
## 自动推进边界
- 自动流是有依赖及状态的执行流程，不是后台定时任务，不代表付费平台已接通。发现真实可用工具，缺工具先完成文档和提示词，登记待执行能力。
- 授权内可逆整理、版本更新和已确认步骤直接继续，不重复询问；缺失只阻断依赖步骤，继续独立工作。
- 付费生成先核对授权、模型、预算/重试及真实接口。企划预算、平均镜数和抽卡次数不是授权或上限。缺必要决定先完成当前关卡允许的可审查资料与缺口说明；不得借此越过资产关卡提前锁定生成包，再集中询问确实缺失的决定。
- 结果不确定先查原任务；登记任务ID、费用（未知则记未知）及重试次数，先诊断后重试，不超授权边界。
- 发布、给供应商发消息和购买音乐按用户明确授权执行；不因自动流增加审批或省略质量关卡。
## 项目隔离与变更
项目九类槽位是唯一参数来源。黄海、人参等其他作品案例不向本项目继承静音、禁字幕、角色或风格；画幅、字幕、BGM、音色、模型未知时标待定。
保留恋综关系推进、观察反应、选择自由和本集钩子。关系方向及反转 Demo 不等于锁定最终配对；常驻、飞行与候选分开登记，多余资产不自动加入正片。
跨包服装、持物手、比例、位置、眼线、坐站和音色继承实际验收结果；待审结果不作为确认续接源。上游变化先回写来源与旧值/新值/原因/日期，再标记受影响资产、分镜、制作包和剪辑需复核，不静默覆盖成片。
## 文件及验证
读 [交付与状态规范](references/交付与状态规范.md) 使用字段及质量关卡。新交付写 vN，保留旧版；登记项目相对路径，制作包使用包内相对引用。
运行 `node scripts/audit_project.cjs <项目根目录>` 检查九类槽位、资产文件、当前技能版本、来源快照及模块引用。原同步清单保留来源哈希，升级版本另记 `漫剧数据库/skill项目版本清单.json`；无Node且未升级项目可用原audit_project.py。结构检查不代替官方技能校验或创作与视听验收；源模块变化先看差异，不自动覆盖。
交付简述完成内容、文件位置、检查与未核验项及下一步。未绑定远端只报告本地保存；搭建 skill 不代表完成剧集制作。
