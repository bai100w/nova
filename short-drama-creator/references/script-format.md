# 正式剧本格式

## 标准格式

```text
第X集

X-1 日/夜 内/外 场景
人物：甲、乙、群众若干

△ 可见、可演、可拍的动作与环境。
甲（状态或动作）：台词。
乙（压低声音）：台词。
甲 OS：内心独白。
甲 VO：画外音。
```

## 写作规则

- 一场只保留一个主要冲突中心。
- 动作描述必须可见、可演、可拍。
- 把“非常痛苦”等抽象词改成表情、动作、停顿和选择。
- 台词尽量短，保留口语节奏和角色差异。
- 不重复观众已知信息。
- 不用大段独白替代事件。
- 删除无意义寒暄、进门、坐下和重复确认。
- 每次场景切换带来信息、冲突或情绪价值。
- 新增昂贵场景、特效或群演时提示制作成本。
- OS 只用于不可见但必要的主观信息；VO 用于画外叙述，不混用。

## 集尾钩子轮换

- 身份揭示
- 信息反转
- 危险逼近
- 关系破裂
- 误会被证据打破
- 能力即将兑现
- 关键人物出现
- 证据曝光
- 主角意外选择
- 胜利后出现更大代价
