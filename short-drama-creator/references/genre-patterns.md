# 题材模式

## 女性成长 / 真假千金

发动机：身份资源不平等 + 主角独立目标。避免把成长写成获得豪门认可或男性拯救。让主角的能力、选择和代价决定结果。

## 豪门情感 / 甜宠

发动机：利益合作与真实情感的冲突。关系推进必须改变信任、边界或共同风险。控制欲和强迫若出现，必须被剧情识别并产生修正成本。

## 复仇 / 战神逆袭

发动机：旧案真相 + 敌人层级。为主角能力设置边界，让胜利需要判断、牺牲或联盟；避免每个敌人只负责挑衅后被秒杀。

## 重生 / 穿越

发动机：已知未来与无法完全控制的变量。明确记忆边界、蝴蝶效应和第二次选择的代价，避免主角靠全知轻松通关。

## 玄学 / 风水 / 神话

发动机：规则型能力 + 更大秩序冲突。先定义能力能做什么、不能做什么、使用代价和验证方式，再设计升级。

## 家庭喜剧

发动机：价值观差异和真实利益。笑点来自人物解决问题的独特方式，不只靠口音、地域刻板印象或连续误会。

## 萌宝

发动机：孩子连接两组关系或秘密。孩子应有年龄相符的欲望和局限，不只作为撮合工具或万能能力者。

## 悬疑

发动机：明确问题 + 可验证线索 + 阶段答案。每次答案同时关闭一个问题、打开一个更深问题；反转不能依赖此前从未出现的信息。
