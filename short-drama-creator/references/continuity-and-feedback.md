# 连续性与反馈学习

## 续写状态

续写前维护：

- 当前时间线与地点
- 人物已知/未知信息
- 关系状态
- 已埋/已兑现伏笔
- 未解决冲突
- 道具与证据
- 能力规则与代价
- 伤势、身份和资源
- 用户已确认设定

不得让人物突然知道不该知道的信息，不遗忘已发生事件，不随意改变能力规则。

## 反馈分级

| 类型 | 作用范围 | 是否持久化 |
|---|---|---|
| 单次修改 | 当前段落或交付 | 否 |
| 项目规则 | 当前项目后续 | 写入项目状态 |
| 长期偏好 | 未来项目 | 用户明确认可后写入 |
| 参考规律 | 特定题材或通用方法 | 验证后写入 |

记录格式：

```text
日期：
来源：
原问题：
修改原则：
适用范围：
例外：
置信度：
用户是否明确认可：
```

## 回归检查

1. 用一句话复述反馈。
2. 判断问题属于创意、人物、结构、节奏、台词、格式或审美。
3. 扫描全文同类问题。
4. 修改目标位置及必要的关联位置。
5. 检查是否破坏人物逻辑、伏笔和后续事件。
6. 新旧规则冲突时引用用户最新明确要求，并标记旧规则失效范围。

## 新参考学习

提取题材、集数、长度、格式、开场机制、主角发动机、冲突阶梯、关系变化、反转和集尾钩子。区分：

- 可迁移规律
- 题材专属规律
- 作者个人风格
- 不应复制的专有表达

用质量量表验证新规律是否改善作品，再决定是否沉淀。
