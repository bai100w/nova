# 证据、可比性与评分

## 五类证据

| 类型 | 定义 | 示例 |
|---|---|---|
| `direct` | 来源直接报告目标结果，且指标定义明确 | 已授权后台中的实际成交、本人官方账号声明 |
| `proxy` | 与目标相关但不能直接证明目标 | 播放、互动、帖子量、排名、搜索热度、评论意向 |
| `estimate` | 基于透明假设和输入的估算 | 由公开区间估计的受众量，必须给范围与方法 |
| `model` | 为决策构建的评分或分类 | 平台相关度、机会优先级、生命周期分类 |
| `inference` | 多条证据共同支持的解释 | 某内容母题可能正从社区向短视频扩散 |

没有平台或商业系统的直接证明时，帖子数、货架量、播放、互动、搜索热度和排名不得称为销量、GMV、收入或转化。商业链接、评论“想买”和商品提及只能作为 `proxy`。

## 证据账本

每条关键证据保留：`source_id`、对象、平台、市场、语言、采集日期、发布时间、时间窗、链接、账号/社区、内容格式、原始指标、指标定义、证据类型、是否官方、是否赞助、样本角色、置信度、限制和对应结论。

搜索摘要不是原页面证据；只有无法访问原页面且摘要确实支持有限事实时才可作为低置信度 `proxy`，并明确说明。

## 跨平台可比性

原始播放、点赞、评论、保存、转发、社区成员、搜索热度和帖子数的分母、窗口和推荐机制不同，不直接横比。优先使用：

1. 平台内同查询、同窗口的分位或排名；
2. 相对账号基线的异常倍数；
3. 互动结构（评论/保存/转发占比）而非单一总量；
4. 多创作者参与和社区持续性；
5. 不同平台是否出现相同母题的独立证据。

任何跨平台综合分都标为 `model`，展示维度、权重、缺失值和敏感性；不输出带小数点的伪精确结论。

## 置信度

- 高：多个独立一手/原始页面、市场与时间一致，关键结论可复核；
- 中：至少两类独立信号支持，但存在样本或指标限制；
- 低：单一来源、搜索摘要、二手引用、封闭社区转述或关键字段缺失。

证据冲突时并列呈现，不用平均数掩盖差异。

## 生命周期

| 状态 | 可观察信号 |
|---|---|
| 萌芽 | 小社区/少数创作者持续出现，新词或新格式刚形成 |
| 加速 | 独立创作者数、发布频率和跨平台迁移同时上升 |
| 峰值 | 高频复制、头部加入、讨论和搜索集中爆发 |
| 衰退 | 新创作者减少、重复率上升、互动相对基线下降 |
| 周期复燃 | 与节庆、版本、赛事、周年或新品节点重复出现 |
| 无法判断 | 时间序列或窗口不足 |

状态是 `model`/`inference`，必须附日期窗口和反证。

## 机会评分

先过硬门槛：版权/商标、隐私与未成年人、品牌安全、平台规则、事实可靠性、制作/履约可行性。硬门槛未通过时，传播分不能抵消风险。

通过后分开评估：信号强度、持续性、对象适配、可执行性、传播/商业路径、证据质量。输出 S/A/B/C/排除或“立即做/测试/观察/不做”，同时给验证动作、成功门槛、调整条件和停止门槛。
