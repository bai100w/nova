# 对象识别与查询扩展

## 对象卡

所有任务先记录：

| 字段 | 要求 |
|---|---|
| 原始标签 | 保留用户原文，不先翻译覆盖 |
| 对象类型 | 商品/品类、品牌、人物、IP、事件、场景/问题、模糊词 |
| 决策问题 | 要发现趋势、找达人、理解 VOC、产脚本或评估机会 |
| 市场与语言 | 国家/地区、主要语言、当地语言和英语 |
| 时间窗 | 起止日期；没有日期时写明默认窗口 |
| 名称集合 | 官方名、别名、旧名、缩写、拼写变体、本地化名、音译 |
| 消歧状态 | 已确认、候选并列、无法确认 |
| 排除词 | 同名污染、无关品类、成人/政治等按任务排除的语义 |

## 通用查询树

从九组词生成查询组合，不要只搜一个 hashtag：核心实体、上/下位词、动作、场景、受众、问题/抱怨、情绪/身份表达、内容格式、商业词。每组保留原文、英语和目标市场当地语言；搜索结果出现新黑话时回填词表并记录来源。

## 商品与品类

扩展：正式品名、消费者俗称、材质/规格、适用对象、使用动作、使用前后、场景、痛点、替代方案、购买疑问、评测/开箱/教程/对比/失败、礼物和季节词。

最小查询矩阵：

```text
[product] + review | problem | how to use | vs | worth it
[scenario] + hack | routine | setup | fail | before after
[audience] + recommendation | complaint | gift | beginner
```

## 品牌与竞品

增加品牌旧名、账号、系列/SKU、创始人、代言人、竞品、替代品、dupe、scam、quality、customer service、recall、collab 等。品牌提及与品类自然内容分开；广告、赞助、联盟链接和自然 UGC 分开。

## 人物

### 同名消歧门

至少使用职业/身份、所属机构或作品、国家/城市、官方账号、官网/资料页、头像或关联事件中的两项交叉确认。候选仍超过一个时，列候选并停止深挖，不得以“最像”“排名最高”代替确认。

不得从姓名、外貌、语言或受众结构推断种族、宗教、性取向、健康、政治倾向等敏感个人属性。只报告本人明确公开且与任务相关的自述，并标注来源。

查询组：姓名变体、账号、机构、作品、访谈、演讲、合作、fan、criticism、controversy、reaction、parody、impersonation、同名排除词。

### 声誉、争议与受众

争议样本逐条区分：公开指控、当事人回应、平台/机构处置、司法或监管记录、独立核验、已证实、未证实、已撤回、仍有争议。标题、匿名帖和单方陈述不能被改写成事实；描述时写清“谁在何时提出什么”，紧邻来源和状态，避免重复不必要的伤害性细节。

受众年龄、地区、职业等仅在平台授权分析、可靠调查或明确自述支持时报告；无法取得时写“受众属性未知”。不得从评论头像、姓名或少量高互动账号外推整个人群。

## 娱乐、游戏、体育或文化 IP

### 名称与世界观

- 官方标题、旧标题、本地化标题、音译、缩写、拼写错误；
- 作品季次、游戏版本/服务器、发行节点、DLC、赛事阶段；
- 角色、阵营、地点、道具、技能、剧情、台词和标志性视觉；
- 关系/CP、Shipping、友情/对立、角色组合、粉丝昵称；
- 社群黑话、内部梗、争议词、剧透词和排除词。

### 二创格式

检索 Fan Art、Cosplay、Edit/AMV、Reaction、Lore、Theory、Meme、Challenge、Dance、Cover、Roleplay、Fanfic、Shipping、Clip、Speedpaint、Merch、Unboxing、Mod、Walkthrough、Stream 和 Podcast。不要猜造不存在的英文名；未知角色/关系先从官方清单或多个独立社群证据发现。

每条样本标记官方与非官方：`official`、`licensed partner`、`creator/fan`、`unclear`。官方发布量和粉丝二创量分别分析。

### 权利边界

把想法分为：

- 可做：事实性讨论、原创评论、获得授权的素材；
- 需授权：角色形象、Logo、官方音乐/片段、商品化和联名；
- 不建议：冒充官方、误导性联名、未经许可复制核心视觉或高风险争议梗。

## 事件与季节

记录事件发生日、预热/爆发/余波窗口、地点和时区；区分突发峰值与可复现周期。查询加入 before/after、live、recap、reaction、prediction、anniversary 和当地节日词。

## 场景、问题与审美

先找同义表达和可观察动作，再找可承载场景的产品或 IP。审美词增加颜色、材质、空间、年代、亚文化、搭配、教程和反向审美词，避免泛词污染。

## 模糊标签

若标签同时可能是人、品牌、地点或作品：

1. 用精确短语和类别词做轻量检索；
2. 列出候选对象及支持证据；
3. 选择需要用户确认的最小字段；
4. 未确认前只交付消歧结果，不合并声量、受众或争议。
