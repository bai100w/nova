# 单文件 HTML 报告契约

## 交付原则

复制 `assets/overseas-social-report-template.html` 到用户指定位置后填充。最终交付必须是一个可直接打开的 `.html` 文件，核心正文、样式、表格、图形替代文本和交互脚本均内嵌。外部字体、CDN 图表和远程图片只能作增强，不能成为读取报告的前提。

模板中的“待填入已核验证据”是空状态，不是正式报告内容。没有可靠数据时保留空状态并说明缺失原因，不生成示例数字、示例达人或伪造链接。

## 必需章节和 ID

| ID | 章节 | 最低内容 |
|---|---|---|
| `summary` | 执行摘要 | 对象、市场、窗口、结论、置信度、3–5 个行动要点 |
| `entity` | 对象与查询树 | 类型、消歧、名称/语言、词组、排除词 |
| `routing` | 平台路由 | 入选主平台、验证平台、区域平台、已排除平台和理由 |
| `evidence` | 数据与证据 | 样本、来源、五类证据、指标限制、缺失项 |
| `trends` | 趋势/Meme/生命周期 | 母题、格式、跨平台共振、阶段、反证 |
| `ugc` | UGC 样本 | 原型、突破、反例、争议、商业样本及链接 |
| `nodes` | 创作者与社区 | KOC/KOL/专家/管理员/桥接节点、匹配和风险 |
| `language` | 关键词与社群语言 | hashtag、查询、联想、俗称、黑话、反向词 |
| `voc` | VOC 与争议 | 喜欢、痛点、问题、替代、身份、不同立场 |
| `scripts` | 内容公式与脚本 | 平台原生格式、钩子、结构、验证和停止门槛 |
| `entity-deep-dive` | 对象专项 | 商品/品牌、人物或 IP 的条件模块 |
| `opportunities` | 机会与风险 | 硬门槛、立即做/测试/观察/不做、证据与反证 |
| `roadmap` | 30/60/90 | 任务、负责人/周期、成功/调整/停止门槛 |
| `sources` | 来源与方法 | 来源索引、采集时间、市场、证据类型、限制 |

导航必须包含指向全部 14 个 ID 的内部链接。

## 页首元数据

显示：报告标题、对象原文、对象类型、目标市场、语言、时间窗、生成/刷新日期、采集平台数、样本数、总体置信度。缺少的字段明确显示“未指定”或“未取得”，不显示 0 造成误解。

完成正式报告后运行：

```powershell
python scripts/validate_report.py "<报告.html>"
```

模板自身可用 `--template` 仅检查结构；正式报告不得使用该参数绕过空状态检查。

## 证据徽标

统一使用 `direct`、`proxy`、`estimate`、`model`、`inference`，同时显示中文解释。颜色只是辅助，文本必须可读。所有重大结论紧邻证据编号或来源链接。

## 表格与样本卡

- 桌面端允许横向密集表格，窄屏使用可滚动容器；
- 不删除列来“适配手机”；
- 所有外链带清晰标题和 `target="_blank" rel="noopener noreferrer"`；
- 数字保留原单位、窗口和指标定义；
- 图形必须有对应表格、列表或 `aria-label`，不能只靠颜色；
- 不使用整页重复的同尺寸卡片；用表格、带编号的论证列表、轨道和时间线匹配信息类型。

## 视觉与交互

- 报告用于分析者在较暗环境阅读高密度信息，因此使用带暖色倾向的深色底，不使用纯黑/纯白；
- 颜色策略为 restrained：橙色主强调，青色验证，紫色模型，红色风险；
- 系统无衬线字体，正文最大 75ch；数据使用等宽数字特性；
- 固定顶部章节导航、当前章节状态和阅读进度；
- 动效只表达导航/展开状态，150–250ms，支持 `prefers-reduced-motion`；
- 禁止渐变文字、默认玻璃拟态、无意义入场动画和装饰性大数字模板；
- 键盘焦点可见，颜色对比满足正常正文阅读，移动端结构不溢出视窗。

## 数据映射

建议使用 `data-field`、`data-list` 和 `data-state` 标记可替换区域。Skill 可以直接编辑 HTML，也可以生成后用确定性脚本替换；无论采用哪种方式，最终文件不得依赖运行时 JSON。

## 完成检查

1. 14 个章节和导航锚点均存在；
2. 未取得证据不会被伪造内容替代；
3. 每个结论可追溯到来源或明确标为 `model/inference`；
4. 已排除平台表存在；
5. 原始跨平台指标没有形成伪排名；
6. 窄屏表格可滚动，正文无需水平滚动；
7. 关闭 JavaScript 后正文和表格仍完整可读；
8. 页面没有控制台错误、无效内部链接和遗留模板说明。
